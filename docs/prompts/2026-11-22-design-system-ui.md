# 디자인 시스템 적용

- 작성일: 2026-11-22
- 관련 이슈 / PR: 미생성. 선행 작업 https://github.com/SiotTUK/Siot-FE/pull/8

## 목적

Figma `design-system` 페이지(348:798)의 색·글자·간격·공통 컴포넌트를 앱 전체 UI에 반영한다.

## 핵심 요청

요약: 사용자가 Figma의 design-system 페이지를 기준으로 앱 전체 UI를 바꿔 달라고 요청했다. 이후 후속 요청으로 화면 바깥 배경 구분, 내 정보 화면, 흰 탑바, 회원 탈퇴 영역, 좌우 여백 16px을 차례로 조정했다. 팀원 PR(#8~#10)이 main에 병합된 뒤에는 팀원 변경에 맞춰 최신 main 위로 옮기기로 결정했다.

## 선택과 이유

| 검토한 방법                                          | 선택 | 이유                                                                                                                    |
| ---------------------------------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------------- |
| shadcn/ui 도입 (Figma 개발 적용 가이드)              | 제외 | CLAUDE.md "별도 UI 프레임워크·Tailwind를 추가하지 않는다". 기존 CSS Modules 공통 컴포넌트에 같은 모양을 입힌다(AI 판단) |
| 토큰 이름을 Figma 변수 이름(`--primary` 등)으로 변경 | 채택 | Figma Dev Mode의 CSS 이름과 코드가 같아 이후 디자인 수정 시 찾기 쉽다(AI 제안)                                          |
| 화면 좌우 여백 24px (간격 규칙 문구)                 | 제외 | 디자인 시스템 화면 프레임이 모두 16px(390 중 358)이다. 처음엔 24px로 했다가 사용자 결정으로 16px                        |
| Pretendard 글꼴을 CDN으로 불러오기                   | 채택 | jsDelivr의 가변 글꼴(dynamic subset)을 `index.html`에서 불러온다. npm 의존성은 추가하지 않았다(AI 판단)                 |
| 회원 탈퇴 제목 빨간색                                | 제외 | 사용자 요청으로 바꿨으나, 디자인 시스템 화면(393:1270)에서 검정임을 확인하고 되돌렸다                                   |

## 반영 내용

- `src/styles.css`: 색(`--primary` `#1769DC` 등 10개), 글자(Display·Title·Heading·Body·Label·Caption), 간격(4~48), 모서리(8·16), 버튼·입력 높이 52px, 좌우 여백 16px. 디자인 시스템에 없는 성공·경고·오류 배경·placeholder·앱 바깥 배경 색은 임시값으로 표시했다.
- 기존 토큰(`--main-100`, `--title-1` 등)을 새 이름으로 일괄 변경했다. 팀원이 추가한 생활 변화 화면(`life-changes.module.css`)도 같은 이름으로 바꿨다.
- 공통 UI: 회색 화면 배경 + 흰 카드(테두리 없음, 16px), Button(주요·보조=연파랑·비활성=회색, 전체 폭 `block`), Field(8px 모서리, 포커스 파랑, 오류 빨강, 라벨 숨김 `hideLabel`), ChoiceCard(선택 시 연파랑), Badge·Alert·Progress, 흰 상단 바·화면 헤더, 하단 바, 확인 패널.
- 넓은 화면(481px 이상)에서 앱 좌우에 경계선·옅은 그림자를 두고 바깥 배경을 한 단계 진하게 해 앱 영역을 구분한다(AI 판단, 디자인 시스템에 바깥 배경 규칙 없음).
- 내 정보·회원 탈퇴는 디자인 시스템 화면 "내 정보 · 탈퇴 확인"(393:1270)을 따른다: 이메일(라벨 위·값 아래) → 언어 선택 칸(번역 아이콘, `LanguageSelect variant="field"`) → 답변 행(값 굵게, 오른쪽 화살표), 로그아웃·탈퇴하기 연파랑 버튼, 흰 경고 카드, 확인 카드([취소] 보조·[탈퇴] 빨강).
- 아이콘: 의존성 없이 `shared/ui/icons.tsx`에 선 아이콘 3개(오른쪽·아래 화살표, 번역)를 SVG로 둔다.
- 기능 화면: 체크리스트 카드·진행률, 홈 행, 챗봇 말풍선을 같은 토큰으로 맞췄다.
- 미반영: 상단 바 알림 버튼, 하단 탭 아이콘, Tabs·아코디언 등 아직 앱에 없는 컴포넌트. 피그마의 "확인 팝업" 글자는 디자인 주석으로 보고 넣지 않았다(AI 판단).
- 피그마와 차이: 디자인 시스템 화면의 상단 바는 배경과 같은 회색이지만 사용자 요청으로 흰색이다. 내 정보 답변 행은 터치 영역을 위해 44px 높이다.

## 2026-11-24 후속: 최신 main 위로 이동

- 요약: 팀원이 PR #8(체크리스트 리뷰 반영)·#9(생활 변화)·#10(작업 기록 규칙)을 병합했다. 사용자 결정에 따라 작업을 `feature/checklist/home`에서 최신 main 기반 `feature/ui/design-system`으로 옮겼다.
- 충돌: 병합된 체크리스트 기록(`2026-11-22-home-checklist.md`) 한 곳. 병합된 기록은 main 내용을 유지하고, 아래 체크리스트 후속은 이 기록에 남긴다.
- 충돌 없이 깨지는 부분: 생활 변화 화면이 예전 색 이름 11곳을 써서 새 이름으로 바꿨다. 진한 본문색(`--body-1`)은 `--foreground`로 옮기고, 열기 버튼은 다른 카드처럼 흰 카드로 맞췄다.
- 기록 규칙 변경(요청 원문 인용 금지)에 맞춰 이 기록의 요청을 요약으로 바꿨다.

## 2026-11-24 후속: 체크리스트 '해당 없음'은 아래로

- 이전 기록: https://github.com/SiotTUK/Siot-FE/blob/main/docs/prompts/2026-11-22-home-checklist.md (PR #8)
- 요약: 사용자가 '해당 없음'을 누른 항목을 아래로 내려 달라고 요청했다(PR #8 병합 전 요청, 미커밋 상태로 함께 이동).
- 반영: `groupItems`가 '해당 없음' 항목을 같은 묶음(내 체크리스트·생활 준비)의 맨 아래로 보낸다. 누르는 즉시 내려가고, 취소하면 원래 자리로 돌아온다. 완료 체크는 자리를 지킨다. 팀원이 바꾼 `keepOrder`(카드 식별자 순서 보관) 뒤에 적용되므로 함께 동작한다. 화면 표시 순서만 바꾸며 기한은 계산하지 않는다.
