# 챗봇 답변 마크다운 렌더링·출처 중복 정리

- 작성일: 2026-11-24
- 관련 이슈 / PR: 이슈 미생성. PR https://github.com/SiotTUK/Siot-FE/pull/16

## 목적

챗봇 답변의 마크다운 기호(`**` 등)가 그대로 보이는 문제와, 같은 문서의 출처가 쪽수만 달리해 여러 개 표시되는 문제를 고친다.

## 핵심 요청

답변 본문을 react-markdown으로 렌더링하고, 출처는 같은 문서를 한 줄로 합쳐 표시한다. 최신 main을 받은 뒤 수정하고, PR 전 확인 작업을 마친 뒤 PR을 올린다.

## 선택과 이유

| 검토한 방법                               | 선택 | 이유                                                                                         |
| ----------------------------------------- | ---- | -------------------------------------------------------------------------------------------- |
| react-markdown으로 답변 본문 렌더링       | 채택 | 사용자 지정. 원시 HTML은 렌더링하지 않아 서버 텍스트를 HTML로 실행하지 않는다.               |
| remark-gfm 함께 추가                      | 채택 | AI 제안. LLM 답변에 자주 나오는 표·취소선·자동 링크를 표시한다.                              |
| 질문(USER)도 마크다운 렌더링              | 제외 | 사용자가 입력한 그대로 보여야 하므로 일반 텍스트로 유지한다.                                 |
| 문서 이름 기준으로 출처 묶기              | 채택 | API에 문서 ID가 없어 `documentName`으로 묶는다.                                              |
| 겹치거나 이어지는 쪽수 범위 병합          | 채택 | "9~10쪽, 10쪽, 10쪽"을 "9~10쪽"으로 줄인다. 떨어진 범위는 쉼표로 이어 한 칩에 표시한다.      |
| 삭제된 문서(이름 없음)끼리 묶기           | 제외 | 같은 문서인지 알 수 없어 쪽수가 잘못 합쳐질 수 있다.                                         |
| MSW 기본 답변을 마크다운·중복 출처로 변경 | 채택 | 실제 BE 응답 형태(마크다운 본문, 같은 문서의 여러 청크)를 목업에서도 재현해 화면을 확인한다. |

## 반영 내용

- `chat-message.tsx`: 답변 본문을 `react-markdown` + `remark-gfm`으로 렌더링한다. 링크는 새 탭으로 연다. 의뢰 안내(referral) 등 나머지 부분은 기존과 같다.
- `chat.module.css`: 말풍선의 `pre-wrap`은 유지하고 마크다운 영역만 `white-space: normal`로 바꾼다. 문단·목록·제목·코드·인용·표 간격을 말풍선 크기에 맞춘다.
- `sources.ts`: `groupSources`로 출처를 문서별로 묶고 쪽수 범위를 병합한다. 원문 링크는 그룹의 첫 링크를 쓴다. 단위 테스트 3개를 추가한다.
- `mocks/handlers/chat.ts`: 기본 답변을 마크다운 본문과 같은 문서의 출처 3건(12~13쪽, 13쪽, 13쪽)으로 바꾼다.
- 의존성: `react-markdown` 10.1.0, `remark-gfm` 4.0.1 추가.

참고: 같은 실행에서 `/home` 화면에 React 중복 key 경고가 출력됐다. 이번 변경과 무관한 화면이며 별도로 확인이 필요하다.
