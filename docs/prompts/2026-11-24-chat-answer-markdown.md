# 챗봇 답변 마크다운 표시

- 작성일 2026-11-24
- 관련 이슈 [SiotTUK/Siot-FE#13](https://github.com/SiotTUK/Siot-FE/issues/13)

## 목적

챗봇 답변에 마크다운 기호가 그대로 표시되는 문제를 해결한다.

## 핵심 요청

사용자용 챗봇의 답변 본문을 `react-markdown`으로 렌더링한다.

## 선택과 이유

| 검토한 방법                   | 선택 | 이유                                                  |
| ----------------------------- | ---- | ----------------------------------------------------- |
| 공통 답변 컴포넌트에서 렌더링 | 채택 | 신규 답변과 대화 기록에 같은 렌더링을 적용할 수 있다. |
| 자료 없음·오류 문구도 렌더링  | 제외 | 고정 안내의 줄바꿈을 유지한다.                        |

## 반영 내용

- 일반 챗봇 답변을 `react-markdown`으로 표시하고 `skipHtml`을 적용한다.
- 답변 본문의 문단 간격과 목록 들여쓰기를 조정한다.
- 개발용 목업 응답에 굵게, 문단, 순서 있는 목록을 넣는다.
- 별도 관리자 검수 화면의 답변은 일반 텍스트로 표시됨을 코드에서 확인한다.

## 검증

| 확인 항목                  | 방법                             | 결과                                                                        |
| -------------------------- | -------------------------------- | --------------------------------------------------------------------------- |
| 타입·린트·형식·테스트·빌드 | Node 24.18.0에서 `npm run check` | 통과, 테스트 97개                                                           |
| 신규 답변과 대화 기록      | Chrome 390×844, MSW 목업         | 굵게·문단·목록과 일반 텍스트 질문 확인                                      |
| 네 가지 언어               | 대화 기록의 언어별 목업 응답     | 한국어·영어·중국어·베트남어 렌더링 및 원시 HTML 요소 제외 확인              |
| 답변과 함께 표시되는 기능  | Chrome 390×844, MSW 목업         | 키보드로 출처 펼치기, 답변 평가, 기관 전화 링크, 자료 없음 안내 줄바꿈 확인 |

실제 백엔드 연동과 실기기 동작은 미검증이다.

- [줄바꿈 리뷰](https://github.com/SiotTUK/Siot-FE/pull/15#discussion_r4676488639)를 반영해 문단과 목록 항목 안에서 줄바꿈을 보존한다.
