# 프론트엔드 루트 정리

- 작성일: 2026-11-24

## 목적

프론트엔드 루트의 초기 참고 자료와 중복 설정을 정리한다.

## 핵심 요청

로컬 `main`과 GitHub의 `main`이 같은 커밋을 가리키는지 확인한 뒤, 새 브랜치에서 프로토타입 이동과 Node 버전 파일 통일을 적용한다.
변경을 커밋하고 PR로 올리며, 작업 기록에는 요청의 목적과 제약을 요약한다.

## 선택과 이유

| 검토한 방법                             | 선택 | 이유                                                                               |
| --------------------------------------- | ---- | ---------------------------------------------------------------------------------- |
| 초기 HTML을 `docs/prototypes/`에 보관   | 채택 | 운영 빌드와 분리된 참고 자료를 문서 아래에 둔다.                                   |
| `.nvmrc`를 Node 버전 파일로 사용        | 채택 | 로컬 환경에서 nvm을 사용하며, CI도 같은 버전 파일을 읽도록 설정할 수 있다.         |
| `.node-version`을 Node 버전 파일로 사용 | 제외 | 현재 로컬 환경에서 `nvm use`로 프로젝트 버전을 선택할 수 있도록 `.nvmrc`를 남긴다. |

## 반영 내용

- `prototypes/index.html`을 `docs/prototypes/index.html`로 옮기고 README, Git 속성, ESLint, Prettier의 경로를 갱신한다.
- 중복된 `.node-version`을 제거하고 CI, README, 작업 지침에서 `.nvmrc`를 참조한다. 고정 버전은 `24.18.0`으로 유지한다.

## 검증

| 확인 항목       | 방법                                             | 결과            |
| --------------- | ------------------------------------------------ | --------------- |
| 브랜치 기준     | GitHub `main`과 로컬 `main`의 커밋 비교          | 둘 다 `e07d1c2` |
| 프로토타입 원본 | 기존 Git 객체와 이동한 파일을 바이트 단위로 비교 | 일치            |

- Node `24.18.0`과 npm `11.20.0`으로 `npm run check`를 실행했다. 타입 검사, 린트, 형식 검사, 테스트 96개, 운영 빌드가 통과했다. 빌드에는 번들 크기 경고가 표시됐다.
- `dist/`에 프로토타입이 포함되지 않음을 확인했다. GitHub Actions 실행은 미검증이다.
- 스크린샷은 화면 변경이 없어 해당 없음.
