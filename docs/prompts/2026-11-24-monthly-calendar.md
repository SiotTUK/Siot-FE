# 생활 달력 월간 일정 조회

- 작성일: 2026-11-24

## 목적

온보딩을 마친 회원이 하단 탭에서 이번 달 생활·세금 일정을 확인할 수 있도록 CAL-02·04의 월간 조회 흐름을 연결한다.

## 핵심 요청

- 로컬 `main`에서 생활 달력 기능 브랜치를 시작한다.
- 하단 탭에서 이번 달 일정 목록을 열고 날짜별로 확인할 수 있게 한다.
- 구현 단계에서는 커밋과 푸시를 보류한다. 이후 PR 요청에 따라 기능과 수정 범위별로 커밋을 나눈다.

## 선택과 이유

| 검토한 방법                              | 선택 | 이유                                                                            |
| ---------------------------------------- | ---- | ------------------------------------------------------------------------------- |
| 이번 달 전체 일정부터 표시               | 채택 | 탭을 열자마자 향후 일정까지 볼 수 있고, 필요한 날짜를 골라 목록을 좁힐 수 있다. |
| 서버가 반환한 기간·개인화·강조 상태 사용 | 채택 | 화면에서 행정 기한이나 강조 조건을 다시 계산할 필요가 없다.                     |

## 반영 내용

- `/calendar` 및 하단 탭을 연결한다. 서버의 서울 기준과 맞춰 월간 조회의 연·월을 정한다.
- 현재 화면 언어로 월간 일정을 요청한다. 쿼리 캐시는 계정·연·월·언어별로 구분하며 세션이 바뀌거나 만료될 때 정리한다.
- 날짜 선택, 기간과 대상 표시, 개인 일정 및 강조 표시, 로딩·빈 목록·실패 후 재시도를 지원한다.
- 320px에서 긴 브랜드명이 언어 선택기를 밀어내던 문제를 상단 바 줄바꿈으로 수정한다.

## 검증

- 타입 검사, 린트, 포맷 검사, Vitest 103개와 프로덕션 빌드를 `npm run check`로 확인한다.

- Chrome 320px 목업 환경에서 로그인과 하단 탭 이동, 날짜 범위, 강조 표시, 네 언어, Tab·방향키, 로딩·빈 목록·실패 후 재시도를 확인한다.

## 남은 작업

- 배포 또는 백엔드 개발 환경에서 로그인한 상태의 월간 일정 응답을 확인한다.
- 현재 BE 코드에서는 개인 일정 제목과 대상 안내를 한국어로 반환한다. 개인 일정 번역은 BE의 응답을 확인한 뒤 후속 범위를 결정한다.

## 2026-11-24 일정 표시 수정

- 날짜 아래에 일정을 파스텔 라인으로 표시한다. 생활 일정은 파랑, 세금은 초록, 체류는 보라를 사용한다.
- 같은 일정은 한 주 안에서 시작일부터 종료일까지 이어진다. 주 경계를 넘으면 같은 색으로 다음 줄에서 이어지고, 기간이 겹치는 일정은 위아래로 나눠 표시한다.
- 주 경계와 일정 중첩을 Vitest로 검사한다. 로컬 미리보기에서 5~10일 일정의 두 주 연결과 18일 일정의 색상 구분을 확인한다.

## 2026-11-24 월 이동 추가
