# 생활 달력에 행사 일정 연결

- 작성일: 2026-11-25
- 관련 요구사항: EVE-03
- 앞선 작업: [생활 달력 PR #18](https://github.com/SiotTUK/Siot-FE/pull/18), [행사 조회 PR #19](https://github.com/SiotTUK/Siot-FE/pull/19)

## 목적

생활 달력에서 생활·세금·체류 일정과 행사를 같은 날짜 기준으로 보고, 선택한 행사 상세를 열 수 있게 한다.

## 핵심 요청

- 표시 중인 달의 두 API를 함께 조회하고, 한쪽 조회에 실패해도 성공한 일정과 개별 재시도를 제공한다.
- 기존 일정 라인을 보존하고 행사 라인은 주당 세 줄까지 표시한다. 숨은 일정 수는 날짜에 표시하고, 날짜 목록에서 전체 항목을 제공한다.
- 행사 상세에서 돌아왔을 때 월과 선택 날짜를 복원한다.

## 반영 내용

- 회원과 연·월별로 행사 달력 쿼리를 추가한다. 계정 언어 변경 시 기존 행사 쿼리 갱신 경로를 사용한다.
- 행사에 유효한 날짜가 한쪽만 있으면 하루 일정으로 처리한다. 행사와 생활 일정은 각각의 식별자를 구분하고, 날짜별 목록은 시작일과 서버 순서를 유지한다.
- 월과 날짜를 URL에 저장하고 기존 행사 상세의 복귀 경로에 생활 달력을 추가한다.
- 목업 행사 기간에 겹침과 월 경계 사례를 포함한다.
