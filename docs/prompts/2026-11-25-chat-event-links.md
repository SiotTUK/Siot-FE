# 챗봇 답변에서 행사 상세 열기

- 작성일: 2026-11-25
- 관련 요구사항: CB-10
- 선행 작업: [행사 조회 PR #19](https://github.com/SiotTUK/Siot-FE/pull/19), [생활 달력·행사 통합 PR #20](https://github.com/SiotTUK/Siot-FE/pull/20)

## 목적

챗봇의 새 답변과 저장된 대화에서 관련 행사를 열고, 상세 화면에서 질문이 있던 대화로 돌아갈 수 있게 한다.

## 핵심 요청

- 행사 항목만 상세 링크로 표시한다. 기존 행사 상세 화면과 404 안내를 재사용한다.
- CB-10 한 건을 리뷰용 PR로 준비한다. PR은 800줄 이하, 커밋은 100~300줄을 목표로 한다.
- 추가·삭제·합계와 예정 커밋 메시지, PR 제목과 본문을 제출한다. 커밋·푸시·PR 생성은 각각 승인 후 진행한다.

## 선택과 이유

| 검토한 방법                                  | 선택 | 이유                                                              |
| -------------------------------------------- | ---- | ----------------------------------------------------------------- |
| 행사 ID를 문자열로 검증하여 상세 경로에 삽입 | 채택 | 행사 상세와 동일한 형식을 적용하고 19자리 ID의 정밀도를 보존한다. |
| 대화 경로를 내부 복귀 대상으로 전달          | 채택 | 저장된 대화와 새 대화에서 동일한 화면 내 복귀 동작을 제공한다.    |

## 반영 내용

- 새 답변과 기록의 `relatedPages`에서 행사 링크를 렌더링한다. 서버 순서와 행사 외 항목의 제목을 유지한다.
- 화면 내 뒤로 가기에서 유효한 대화 경로를 지원한다. 홈, 행사 목록, 달력 경로의 기존 처리는 유지한다.
- 기존 목업 행사 데이터를 챗봇 행사 응답에서 재사용한다.

## 검증

| 확인 항목             | 방법                                                                    | 결과                                                                                                                                               |
| --------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정적 검사·테스트·빌드 | Node 24.18.0에서 `npm run check`                                        | 타입·린트·포맷·Vitest 139개·프로덕션 빌드 통과. 번들 크기 경고가 출력됐다.                                                                         |
| 새 답변과 대화 기록   | Chrome 320×800, MSW                                                     | 행사 상세 이동과 같은 대화 복귀를 각각 확인했다. `NO_EVIDENCE`·`ERROR` 응답의 행사 링크, 행사 외 항목의 일반 텍스트와 서버 순서를 확인했다.        |
| 모바일 표시·예외 흐름 | Chrome 320×800, MSW                                                     | 네 언어의 긴 제목 줄바꿈과 포커스 윤곽선, 404 안내, 503 이후 재시도, 홈·행사 목록·달력 복귀를 확인했다. 홈에서 기존 React 중복 키 경고가 출력됐다. |
| 키보드 이동           | 인앱 브라우저, MSW                                                      | Tab으로 행사 링크에 포커스를 이동한 뒤 Enter로 상세를 열고 같은 대화로 돌아왔다.                                                                   |
| 실제 API 응답         | 로컬 백엔드의 임시 계정으로 행사 목록·추천, 챗봇 질문, 저장된 답변 조회 | 모두 HTTP 200. 진행·예정 행사와 추천은 각각 0건. 챗봇 응답은 `ERROR`이며 행사 링크는 0건. 임시 계정 정리 완료.                                     |

미검증: 실제 백엔드에 표시할 행사 링크가 없어 해당 링크에서 상세를 여는 흐름은 목업으로 확인했다.

## 남은 작업

- 생활수칙과 체크리스트 상세 링크는 각 상세 화면이 준비되면 연결한다.
