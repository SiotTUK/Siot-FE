# 추천 행사 및 행사 조회

- 작성일: 2026-11-25
- 앞선 1차 연동: [생활 달력 PR #18](https://github.com/SiotTUK/Siot-FE/pull/18)

## 목적

홈 추천 카드에서 행사 상세로 이동하고, 전체 행사 목록에서도 같은 상세 화면을 열 수 있게 한다.

## 핵심 요청

- 참고 화면의 가로 추천 카드, 2열 행사 목록, 상세 정보 배치를 기존 앱에 적용한다.
- 추천·목록·상세 조회를 기존 백엔드 API로 연결한다.
- PR을 검토하기 쉽게 커밋당 추가·삭제 합계를 100~300줄로 나누고 본문과 작업 기록을 준비한다.

## 선택과 이유

| 검토한 방법                  | 선택 | 이유                                                                                                                  |
| ---------------------------- | ---- | --------------------------------------------------------------------------------------------------------------------- |
| 서버의 추천 순서와 사유 사용 | 채택 | 현재 API는 온보딩 태그 일치, 다문화 여부, 시흥 지역, 시작일 순으로 추천한다. 이 순서를 화면에서 다시 계산하지 않는다. |
| 초기 그라데이션 커버         | 채택 | 행사 응답에 이미지 필드가 없고 참고 화면에도 기본 커버가 있다.                                                        |
| 행사 알림 토글 및 목록 필터  | 보류 | 알림 수정 API와 후속 범위가 필요하다. 1차 작업은 추천·목록·상세를 여는 흐름으로 정한다.                               |

## 반영 내용

- 홈 추천 가로 목록, 전체 행사 2열 목록과 페이지 이동, 행사 상세를 연결한다.
- 서버가 제공한 번역과 추천 사유를 표시한다. 언어 저장 이후 행사 조회를 갱신하고, 온보딩 정보 저장 이후 추천을 갱신한다.
- 상세에서 일정, 장소, 가격, 신청 마감, 내용과 신청·원문 링크를 제공 가능한 값에 맞춰 표시한다.
- 조회 대기, 빈 응답, 실패와 재시도, 삭제된 행사 상태를 처리한다.

## 검증

- `npm run check`로 타입, 린트, 포맷, 테스트 106개, 프로덕션 빌드를 확인한다.
- Chrome 모바일 목업에서 홈 추천의 순서와 추천 사유, 키보드 상세 진입, 신청 링크가 있을 때와 원문만 있을 때, 2열 목록, 네 언어 전환, 빈 목록과 없는 행사 상태를 확인한다.

## 남은 작업

- 실제 로그인 세션으로 추천·목록·상세 응답을 확인한다.
- 달력 및 챗봇 상세 연결과 행사 관리는 후속 차수에서 진행한다.

## 2026-11-25 홈 링크 및 썸네일 수정

- 홈의 전체 행사 링크를 추천 제목과 같은 줄 오른쪽에 배치한다.
- 추천·목록·상세 커버에 선택적 썸네일 URL을 지원한다. 사진이 없거나 불러오지 못하면 디자인시스템의 기본 파란색을 표시한다.
- 현재 백엔드 응답은 썸네일 필드를 제공하지 않는다. 프론트에서 선택적 `thumbnailUrl` 수신에 대비하며 사진 등록 계약을 확인해야 한다.
- 목업 홈에서 링크의 우측 정렬을 검증하고, 추천·목록 카드와 상세의 파란색 기본 커버를 확인한다.

## 2026-11-25 PR #19 리뷰 반영

- 온보딩 저장 성공 시 진행 중인 추천 조회를 취소하고 새 답변 기준으로 다시 조회한다.
- 요청한 목록 페이지가 범위를 벗어나면 URL을 유효한 마지막 페이지로 교체한다. 전체 목록이 비어 있으면 첫 페이지로 돌아간다.
- 시작일이 없는 행사는 백엔드와 같은 기준으로 종료일을 사용해 카드 상태를 표시한다.
- `npm run check`를 통과한다. Chrome 390 × 844 목업에서 이전 추천 응답이 늦게 도착해도 저장 후 추천이 유지되는지, 페이지 복구와 빈 목록, 이전 페이지 버튼, 네 언어의 상태 배지를 확인한다. 실제 API는 미검증이다.
