# 생활수칙 화면

- 작성일: 2026-11-25
- 관련 이슈 / PR: 미생성. 이전 작업 https://github.com/SiotTUK/Siot-FE/pull/11

## 목적

1차 로드맵(수지, 11/24~25)의 생활수칙 화면을 연다. 하단 탭 → 목록 → 상세에서 제목·본문·출처를 표시한다.

## 핵심 요청

요약:

- 처음에는 로드맵대로 BE API(`GET /api/rules`, `GET /api/rules/{code}`)를 연결하고 Figma를 참고해 화면을 만들라는 요청이었다.
- 운영 BE에 생활수칙 데이터가 0건이었다. BE main에는 데이터를 넣는 마이그레이션이 없고, 관리자 등록 API는 병합되지 않은 `ksh` 브랜치에만 있었다.
- 사용자는 생활수칙이 잘 바뀌지 않는 고정 안내라고 보고, BE 없이 프론트에 내용을 두기로 결정했다. 내용은 사실 확인을 거쳐 만들고, Figma를 참고하되 디자인은 현재 코드 스타일을 유지하라고 했다.

## 선택과 이유

| 검토한 방법                                        | 선택 | 이유                                                                                                                                                                            |
| -------------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BE API 연결 유지 + BE에 데이터 등록 요청           | 제외 | AI가 권했으나 사용자가 FE 고정 내용으로 결정했다. 다른 기능(챗봇 관련 화면, 관리자 문구 수정)과의 연결, 내용 변경 시 배포 필요, 로드맵의 "실제 API" 기준과 다르다는 점을 알렸다 |
| 프론트 고정 내용(`features/rules/content.ts`)      | 채택 | 사용자 결정. 4개 언어 문구와 출처를 한 파일에 둬 수정 위치를 하나로 한다                                                                                                        |
| 사실 확인                                          | 채택 | 시흥시·정부 공식 페이지만 근거로 썼다. 페이지를 직접 열어 확인한 내용만 넣고, 항목마다 출처 링크와 확인일(2026-11-25)을 표시한다                                                |
| Figma M06 구성(검색·분류 칩·FAQ TOP 5·분야별 안내) | 채택 | 데이터가 FE에 있어 2차로 미뤘던 검색·분류·FAQ도 추가 API 없이 만들 수 있다                                                                                                      |
| 분류 이름 번역                                     | 채택 | 분류를 코드(`order`·`waste`·…)로 두고 화면 문구로 4개 언어를 준다                                                                                                               |

## 반영 내용

- 내용: 6개 분류, 18개 항목, 자주 묻는 질문 5개. 4개 언어.
  - 기초 질서: 층간소음, 금연구역
  - 쓰레기: 생활 쓰레기(종량제 봉투), 음식물, 분리수거, 대형 폐기물
  - 교통: 주정차 금지 구역, 주정차 단속 알림(휘슬)
  - 세금: 주민세, 재산세, 자동차세, 납부 방법과 가산세
  - 생활 편의: 시흥화폐 시루, 자전거 대여소
  - 교육·상담: 1345, 시흥시외국인복지센터, 다누리콜센터·가족센터, 일자리·근로 상담
- 확인하지 못해 뺀 것: 시흥패스+(대상·금액·외국인 이용 여부), "빼기" 앱(시흥시 공식 페이지에 없음), 시흥시 조례상 금연구역 과태료, 종량제 봉투 가격, 자전거 대여 요금, 공공예절.
- 화면: 목록(검색, 분류 칩, FAQ TOP 5 접기, 분야별 안내 접기), 상세(제목 카드, 안내 항목, 정보 행, 출처와 확인일). 공통 `Accordion`·`ChipGroup` 추가, 기존 디자인 토큰 사용.
- 분야별 안내는 Figma M06(393:1105)에 맞췄다: 그룹 이름은 긴 이름(쓰레기 배출 등, 칩은 짧은 이름), 닫힌 카드는 "이름 · 주제어", 열린 카드는 큰 제목 아래 회색 주제어와 항목 링크(요약 없음), 끝에 "○○ 전체 보기"(그 분류 칩으로 전환). 요약은 검색 결과에만 보인다. 공통 `Accordion`에 이 열린 모양을 `hint`가 있을 때만 적용한다.
- 이어서 사용자가 디자인도 Figma를 보라고 해 모양을 M06에 맞췄다: 제목은 Heading(20px)과 16px 간격, 검색창 왼쪽 돋보기 아이콘(`SearchIcon`), 분류 칩은 선택된 것만 작은 뱃지·나머지는 글자, 접기 카드 사이 16px·제목 굵기 600·"이름 · 주제어" 같은 굵기, 열린 분야 카드는 화살표 없음·링크 간격 34px. FAQ 답변 아래 "자세히 보기" 링크는 Figma에 없지만 상세로 가는 길이라 남겼다(AI 판단). 상단 바(지구 아이콘·알림)와 하단 탭 아이콘은 모든 화면의 공통 부분이라 범위에서 뺐다.
- 이어서 사용자가 시안 이미지를 보여 주며 항목 구간이 나뉘지 않은 점을 짚어, 목록을 시안대로 바꿨다: 자주 묻는 질문은 테두리 카드 한 장 안의 "Q." 줄(구분선, ▼/▲), 분야 카드는 왼쪽 아이콘 칸·굵은 이름·작은 주제어·▼, 펼치면 파란 테두리·파란 이름, 항목은 구분선으로 나뉜 줄과 `›`, 끝에 "○○ 전체 보기 →". 시안의 회색 아이콘 칸에는 분야별 선 아이콘을 넣었다(AI 판단). 공통 `Accordion`은 쓰이지 않게 되어 지우고, `RuleFaqList`·`RuleCategoryCard`로 나눴다.
- 이어서 사용자가 폭이 모자라 줄이 바뀔 때 어순에 맞게 배치해 달라고 해, 공통 스타일(`styles.css`)을 바꿨다: 한국어(`:lang(ko)`)는 어절 단위로만 줄바꿈(`word-break: keep-all`, 중국어는 그대로), 제목은 줄 길이를 고르게(`text-wrap: balance`), 문단·목록은 마지막 줄에 한 단어만 남지 않게(`text-wrap: pretty`). 전화번호는 하이픈에서 끊기지 않도록 공통 `KeepTogether`로 묶어 생활수칙 상세·FAQ 답변에 적용했다. 앱 전체 한국어 화면에 적용된다.
- 2026-11-26: 사용자가 Figma 탑바 이미지를 주며 탑바도 바꿔 달라고 했다. 언어 선택을 지구 아이콘 + 언어 이름(`LanguageSelect variant="inline"`, 기본 select 유지)으로 바꾸고, 회원 화면에 알림 종 버튼(`TopBarIconButton`)을 넣었다. 알림 화면·안 읽은 개수(NTF-04)는 로드맵상 다음 작업이라 버튼은 비활성("준비 중")이고 Figma의 숫자는 표시하지 않는다(AI 판단). 로그인·가입 화면에는 종을 두지 않는다.
- 하단 탭 "생활 수칙" 활성화, 라우터 `/rules`·`/rules/:code`.
- 화면 언어는 `t()`가 쓰는 `i18n.language`로 고른다. `currentLanguage()`(`resolvedLanguage`)는 언어 전환 직후 이전 언어가 남아 내용과 문구가 어긋났다.
- 처음 만든 BE API 연결 코드·MSW 목업·계약 테스트는 지웠다.

## 2026-11-26 PR #23 리뷰 반영

- 생활수칙은 프런트엔드 고정 데이터로 유지한다. 지방세법 제75조·제79조와 시흥시 납부기한 안내를 대조해 주민세 개인분 제외 대상과 재산세 대상별 납부 시기를 4개 언어에 반영한다. 주민세 상세와 FAQ는 같은 문구를 사용한다.
- 목록 검색어와 분류를 URL에 보관한다. 목록에서 상세를 열면 이전 기록으로 돌아가 검색어와 분류를 복원한다. 상세 주소로 직접 들어온 경우에는 기본 목록으로 이동한다.
- 분야 카드의 전체 보기를 실행하면 선택한 분류 칩으로 키보드 초점을 옮긴다.
- Chrome 320×800에서 MSW 로그인 후 검색·분류 복원, 직접 진입과 FAQ 상세에서 목록 복귀, 선택한 칩에 초점 이동, 세금 안내의 4개 언어 표시를 확인했다.
- Node 26.13.1에서 `npm run check`로 타입·린트·포맷·Vitest 151개·프로덕션 빌드를 확인했다. 빌드에서 번들 크기 경고가 출력됐다.
