# 시작·회원가입 화면을 Figma v2에 맞춤

- 작성일: 2026-11-27
- 관련 이슈 / PR: 미생성

## 목적

Figma "웰컴시흥 · 주요 화면 UI"의 "시작 · 회원가입" 묶음(F01 언어 선택, M02b 회원가입, M02a 로그인, M02c 비밀번호 재설정, M02d 새 비밀번호 설정)에 맞춰 다섯 화면의 디자인을 바꾼다. 다른 화면은 바꾸지 않는다.

## 핵심 요청

요약: 사용자가 Figma 링크를 주며 "시작 · 회원가입" 부분만 보고 그 부분의 디자인만 바꿔 달라고 했다. AI가 지금 화면과 비교한 뒤 세 가지를 물었고, 사용자가 정했다.

## 선택과 이유

| 검토한 방법                                    | 선택 | 이유                                                                                                               |
| ---------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------ |
| M02a~d 헤더를 Figma대로 "‹ 제목" 뒤로가기 헤더 | 채택 | 사용자 결정. 언어는 F01에서 고르고, 이 화면들에서는 바꿀 수 없다                                                   |
| 로고·언어 선택 탑바 유지                       | 제외 |                                                                                                                    |
| 마스코트 그림을 Figma에서 받아 넣기            | 채택 | 사용자 결정. 시흥시 공식 캐릭터라 형태·색·비율을 바꾸지 않고, 출처를 `src/shared/assets/mascot/README.md`에 남겼다 |
| 이 다섯 화면만 Figma v2 색                     | 채택 | 사용자 결정. 앱 전체 색은 그대로 두고 이 화면들에만 v2 색을 덮어쓴다(AI는 앱 전체와 맞추는 쪽을 추천했었다)        |

## 반영

- `src/app/auth-theme.module.css`·`AuthLayout`: F01·M02a~d에만 Figma v2 색(Brand `#1987c2`, Tint `#e3f3f7`, Ink `#1a1f27`, Canvas `#f5f7f6`, Error `#c7363f`)을 CSS 변수로 덮어쓴다.
- `router.tsx`: F01은 탑바를 유지하고, M02a~d는 탑바 대신 각 화면의 `ScreenHeader`(‹ 뒤로 + 제목)를 쓴다. 뒤로: 회원가입·로그인 → 언어 선택, 재설정 두 화면 → 로그인.
- 새 공통 컴포넌트 `MascotTip`(Figma "웰컴시흥/MascotTip"): 해로(환영, Haero Tint 배경)·토로(도우미, Toro Tint 배경)와 이름·한 줄 안내. 그림은 장식이라 `alt=""`.
- F01: 해로·토로 그림, 제목 아래에 다른 세 언어의 "언어를 골라 주세요"를 한 줄로, 카드에 화면 언어로 쓴 언어 이름(`Intl.DisplayNames`, 같은 이름이면 영어 이름), 아래 안내와 로그인 링크를 왼쪽 정렬.
- M02b: 해로 안내, 비밀번호 규칙을 한 줄로 이어 보여 줌, "가입하면 바로…" 안내를 버튼 아래 작은 글씨로. Figma처럼 아래 "이미 회원이에요? 로그인" 링크는 뺐다(뒤로 가면 언어 선택 화면에 로그인 링크가 있다).
- M02a: 토로 안내, 아래 링크 두 개를 왼쪽 정렬 링크로.
- M02c: "메일을 보냈어요"를 흰 테두리 카드로.
- M02d: 만료 안내를 제목+설명 카드("링크가 만료됐어요" / "30분이 지났거나 이미 쓴 링크예요…")로.
- `ChoiceCard`: `lang`을 버튼 전체가 아니라 제목에만 붙인다(설명은 화면 언어라서).
- 문구 4개 언어 추가: `authTips.*`(마스코트 이름·안내·만료 안내).
