# 시작·회원가입 화면을 Figma v2에 맞춤

- 작성일: 2026-11-27
- 관련 이슈 / PR: 미생성

## 목적

Figma "웰컴시흥 · 주요 화면 UI"의 "시작 · 회원가입" 묶음(F01 언어 선택, M02b 회원가입, M02a 로그인, M02c 비밀번호 재설정, M02d 새 비밀번호 설정)에 맞춰 다섯 화면의 디자인을 바꾼다. 다른 화면은 바꾸지 않는다.

## 핵심 요청

요약: 사용자가 Figma 링크를 주며 "시작 · 회원가입" 부분만 보고 그 부분의 디자인만 바꿔 달라고 했다. AI가 지금 화면과 비교한 뒤 세 가지를 물었고, 사용자가 정했다.

## 선택과 이유

| 검토한 방법                                    | 선택 | 이유                                                                                                               |
| ---------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------ |
| M02a~d 헤더를 Figma대로 "‹ 제목" 뒤로가기 헤더 | 채택 | 사용자 결정. 언어는 F01에서 고르고, 이 화면들에서는 바꿀 수 없다                                                   |
| 로고·언어 선택 탑바 유지                       | 제외 |                                                                                                                    |
| 마스코트 그림을 Figma에서 받아 넣기            | 채택 | 사용자 결정. 시흥시 공식 캐릭터라 형태·색·비율을 바꾸지 않고, 출처를 `src/shared/assets/mascot/README.md`에 남겼다 |
| 이 다섯 화면만 Figma v2 색                     | 채택 | 사용자 결정. 앱 전체 색은 그대로 두고 이 화면들에만 v2 색을 덮어쓴다(AI는 앱 전체와 맞추는 쪽을 추천했었다)        |

## 반영

- `src/app/auth-theme.module.css`·`AuthLayout`: F01·M02a~d에만 Figma v2 색(Brand `#018eda`(사용자 결정, Figma 값은 `#1987c2`), Tint `#e3f3f7`, Ink `#1a1f27`, Canvas `#f5f7f6`, Error `#c7363f`)을 CSS 변수로 덮어쓴다.
- `router.tsx`: F01은 탑바를 유지하고, M02a~d는 탑바 대신 각 화면의 `ScreenHeader`(‹ 뒤로 + 제목)를 쓴다. 뒤로: 회원가입·로그인 → 언어 선택, 재설정 두 화면 → 로그인.
- 새 공통 컴포넌트 `MascotTip`(Figma "웰컴시흥/MascotTip"): 해로(환영, Haero Tint 배경)·토로(도우미, Toro Tint 배경)와 이름·한 줄 안내. 그림은 장식이라 `alt=""`.
- F01: 해로·토로 그림, 제목 아래에 다른 세 언어의 "언어를 골라 주세요"를 한 줄로, 카드에 화면 언어로 쓴 언어 이름(`Intl.DisplayNames`, 같은 이름이면 영어 이름), 아래 안내와 로그인 링크를 왼쪽 정렬.
- M02b: 해로 안내, 비밀번호 규칙을 한 줄로 이어 보여 줌, "가입하면 바로…" 안내를 버튼 아래 작은 글씨로. Figma처럼 아래 "이미 회원이에요? 로그인" 링크는 뺐다(뒤로 가면 언어 선택 화면에 로그인 링크가 있다).
- M02a: 토로 안내, 아래 링크 두 개를 왼쪽 정렬 링크로.
- M02c: "메일을 보냈어요"를 흰 테두리 카드로.
- M02d: 만료 안내를 제목+설명 카드("링크가 만료됐어요" / "30분이 지났거나 이미 쓴 링크예요…")로.
- `ChoiceCard`: `lang`을 버튼 전체가 아니라 제목에만 붙인다(설명은 화면 언어라서).
- 문구 4개 언어 추가: `authTips.*`(마스코트 이름·안내·만료 안내).

## 2026-11-27 후속: PR #64 셀프 리뷰의 사소한 두 가지

- 요약: 사용자가 PR #64 리뷰를 요청했다. AI가 글자 대비(P2), 뒤로가기 목적지, 쓰지 않는 문구 키를 짚었고, 사용자가 사소한 두 가지만 먼저 고치자고 했다. 글자 대비는 아직 그대로다.
- 반영: 화면 사이 링크가 출발 화면을 `state.back`으로 넘기고, ‹는 그 화면(언어 선택·회원가입·로그인·재설정 요청 중 하나일 때만)으로 돌아간다. 없으면 전처럼 정해진 화면으로 간다. 브라우저 뒤로가기(`history.back`)는 만료된 세션으로 /login에 온 경우 회원 화면으로 돌아갈 수 있어 쓰지 않았다. 이번 변경으로 쓰지 않게 된 `signup.haveAccount`·`signup.login`·`newPassword.invalid`를 4개 언어에서 지웠다.
- 검증: `npm run check` 통과(Vitest 227개). 목업에서 회원가입·로그인을 바로 열면 ‹가 언어 선택(`/`)으로, 로그인 → 회원가입 링크로 오면 ‹가 로그인으로, 로그인 → 재설정 요청과 새 비밀번호 화면은 ‹가 로그인으로 가는 것을 확인했다.

## 2026-11-27 후속: 브랜드 색을 #018EDA로

- 요약: 리뷰에서 Figma 파란색의 글자 대비가 접근성 기준(4.5:1)에 못 미친다고 짚고 어두운 `#1574a7`을 제안했는데, 사용자가 Color/Brand를 `#018EDA`로 통일하자고 정했다.
- 반영: `auth-theme.module.css`의 `--primary`를 `#018eda`로, 누를 때 색 `--primary-hover`를 `#0172ae`로 바꿨다. 이 색은 F01·M02a~d에만 쓰인다(다른 화면은 기존 `#1769dc`).
- 참고: `#018eda`는 더 밝아 대비가 더 낮다. 흰 버튼 글자 3.57, 배경 위 링크 3.32, 보조 버튼 글자 3.13, 해로 이름 3.21로 4.5에 못 미친다. 사용자에게 알렸다.
- 검증: `npm run check` 통과. 목업 화면에서 버튼·링크·해로 이름 색 확인.
