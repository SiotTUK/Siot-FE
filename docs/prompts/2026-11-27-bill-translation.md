# 고지서 사진 번역

- 작성일: 2026-11-27
- 관련 이슈: [Siot-FE #28](https://github.com/SiotTUK/Siot-FE/issues/28), [Siot-FE #44](https://github.com/SiotTUK/Siot-FE/issues/44), [Siot-BE #17](https://github.com/SiotTUK/Siot-BE/pull/17)

## 목적

홈에서 사진이나 PDF를 올려 고지서를 번역하고, 사용자 언어로 납부 정보를 확인할 수 있게 한다.

## 핵심 요청

- M11a~M11d, 홈 진입점, 4개 언어 문구, MSW 계약 테스트를 구현한다.
- 최신 BE main 계약에 맞춰 번역 기록과 D-7·D-1 알림을 연결한다.
- 구현과 검사 후 변경 내용을 로컬 작업 브랜치로 옮긴다. 커밋과 원격 반영은 승인 후 진행한다.

## 선택과 이유

| 검토한 방법                            | 선택 | 이유                                                                                     |
| -------------------------------------- | ---- | ---------------------------------------------------------------------------------------- |
| 최근 번역과 알림을 BE에 연결           | 채택 | 읽을 수 있는 결과는 저장되며 목록, 상세, 삭제, 알림 변경 API가 있다.                     |
| 공통 API 클라이언트에서 multipart 처리 | 채택 | 기존 세션 쿠키, CSRF 갱신과 1회 재시도, 오류 파싱을 재사용한다.                          |
| 처리 중 단계를 순서대로 나열           | 채택 | 단일 업로드 응답으로 완료를 확인할 수 있어 처리 중에는 완료율 대신 대기 상태를 표시한다. |
| 납부일을 기준으로 D-day 표시           | 채택 | BE가 문서에서 읽은 기한을 사용해 한국 날짜 기준으로 남은 일수만 표시한다.                |

## 반영 내용

- 카메라·앨범·PDF 선택, 10MB 상한, 외부 AI 전송 동의, 첨부 미리보기 및 취소를 구현한다.
- 자동 저장된 번역의 요약, 주의 사항, 원문, 관련 안내와 마감 알림을 표시한다. 인식 실패 시 사유별 재촬영 방법을 제공한다.
- 기존 버튼, 카드, 스위치와 문서 UI를 사용한다. 최근 번역과 상세 캐시는 계정별로 관리한다.

## 검증

| 확인 항목   | 방법                | 결과                                                                                                                             |
| ----------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 전체 검사   | `npm run check`     | 타입·린트·형식·빌드 통과. Vitest 25개 파일, 194개 테스트 통과.                                                                   |
| 모바일 목업 | Chrome 400×799, MSW | 네 언어의 업로드 화면을 확인한다. 사진 선택·동의·키보드 제출·처리 중 취소·결과 및 원문 대조·최근 기록·인식 실패 화면을 확인한다. |

미검증: 실제 BE·Gemini, 실기기 카메라와 PDF 뷰어, 실제 알림 발송, 10초 지연 문구의 브라우저 표시는 확인하지 않았다. 빌드에서 500kB 초과 청크 경고가 표시됐다.

### 2026-11-27 추가 모바일 검증

- PR 제출 전 Chrome 터치 에뮬레이션으로 360×800, 390×844, 400×799에서 한국어·영어·중국어·베트남어를 조합해 12개 환경을 점검한다. 로컬 MSW와 합성 문서를 사용한다.
- 360×800 베트남어에서 긴 파일명을 선택하면 처리 중 취소 버튼의 하단이 뷰포트 800px보다 낮은 875px, 지연 문구 표시 후 903px에 위치한다. 문서 미리보기 높이를 뷰포트에 맞추고 문서 로딩 표시의 상하 여백을 줄인다. 재검증에서 12개 조합 모두 취소 버튼이 첫 화면 안에 표시된다.
- 공통 스위치의 장식 요소가 입력 위에서 터치를 가로채지 않게 한다. 접근성 이름에는 제목을 사용하고 안내는 설명으로 전달한다. 마감 알림을 켜기·끄기 양방향으로 점검한다.
- M11a 파일 선택·10MB 초과 거절·AI 동의·최근 기록 열기 및 삭제, M11b 사진 미리보기·10초 지연 안내·취소 후 복귀, M11c PDF 업로드·첫 페이지 안내·결과·원문 대조, M11d 인식 실패 3종과 재촬영 선택창을 확인한다.
- 조합별 14개 상태에서 긴 파일명, 길게 늘린 번역과 공백 없는 190자 응답 필드의 가로 스크롤·컨트롤 겹침·글자 잘림을 점검했다. 재검증에서 168개 상태가 통과했다. PR 첨부용 전체 페이지 PNG 96장과 측정 결과는 저장소 밖의 검증 ZIP에 준비한다.
- 12개 조합 모두 요청 취소 뒤 업로드 화면으로 돌아왔다. 시험한 12개 조합에서 목업 처리는 계속되어 취소한 요청이 최근 기록에 뒤늦게 저장됐다. 현재 BE 계약에는 진행 중인 번역을 취소하는 API가 없다.
- 실제 스마트폰의 카메라·앨범·시스템 파일 선택창·내장 PDF 뷰어, 실제 BE·Gemini 연동과 알림 발송은 미검증이다.
- 모바일 수정 후 `npm run check` 재실행 결과는 타입·린트·형식·프로덕션 빌드 통과와 Vitest 194개 통과다. Vite의 500kB 초과 청크 경고가 표시됐다.

### 2026-11-27 해로토로 v2 시안 반영

- [최신 Figma](https://www.figma.com/design/Vmv4427fMsMvSde21EiSsy?node-id=456-2)에서 M11a~M11d를 확인했다. 승인된 범위는 고지서 번역 화면과 기능 전용 문구, 이 작업 기록이다.
- M11a에 주황색 소개 카드, 화면에 직접 배치한 촬영·앨범·PDF 버튼, 접이식 촬영 팁, 최근 기록의 문서 아이콘을 추가한다. M11b는 중앙 안내와 상태 카드 중심으로 배치하고 작은 첨부 미리보기, 10초 지연 안내 및 첫 화면에서 누를 수 있는 취소를 유지한다.
- M11c는 납부 기한과 D-day를 상단에 배치하고 원본 확인 문구와 원문 대조를 분리한다. 하나의 스위치에서 D-7·D-1 오전 9시(한국 시간) 알림을 함께 설정한다. ‘완료 · 저장’은 서버가 저장한 결과를 확인하고 최근 번역으로 이동한다. 문서 종류 정정과 별도의 세금 상세 경로는 이번 화면에 연결하지 않는다.
- M11d는 사유별 실패 카드와 다시 시도, 앨범·카메라 버튼을 제공한다. 기존 챗봇과 전화 문의는 보조 동작으로 둔다. 개인정보에는 BE의 외부 AI 전송 동의, 원본 미저장 및 개인정보를 가린 결과 저장 안내를 적용한다.
- [시흥시 공식 목록](https://www.siheung.go.kr/main/character/list.do?CATEGORY=1&mId=0501040100)에서 3D 원본 다운로드 항목을 찾았다. 시안의 포즈와 일치하며 프로젝트에서 사용할 수 있는 원본을 확보하지 못해 마스코트는 미반영 상태다.
- Chrome 모바일 에뮬레이션에서 360×800, 390×844, 400×799와 한국어·영어·중국어·베트남어를 조합해 로컬 MSW로 12개 조합, 168개 화면 상태를 확인한다. 가로 넘침·컨트롤 겹침·글자 잘림이 없었고, 긴 파일명에서도 취소 버튼은 첫 화면에서 누를 수 있었다. 완료 후 추가 POST가 없음을 확인한다. 합성 파일을 사용한 전체 페이지 PNG 96장과 측정값은 저장소 밖 검증 ZIP에 준비한다.
- `npm run check`에서 타입·린트·형식·Vitest 194개·프로덕션 빌드가 통과한다. Vite는 500 kB 초과 청크 경고를 표시한다. 실기기 카메라·앨범·파일 선택창·PDF 뷰어, 실제 BE·Gemini와 알림 발송은 미검증이다.
- 기존 미커밋 공통 UI 변경을 보존한다. 이번 반영은 고지서 화면 코드 6개 파일과 이 기록에 한정한다.

### 2026-11-27 최신 main 통합 검증

- 기존 #28 커밋과 미커밋 파일을 백업한 뒤 최신 `origin/main` `b09db9f`와 합친 코드를 격리된 작업본에서 준비한다. 기존 공개 커밋의 이력을 보존하기 위해 실제 통합 방식은 merge를 선택한다. 원본 브랜치에서는 승인된 작은 로더 변경만 제거한다.
- 홈의 형제 컴포넌트 키에 main의 접두사를 유지하고 체크리스트 키에 가이드 코드도 포함한다. 체크리스트는 가이드 항목 펼침·스크롤·포커스와 main의 `markErrorMessage`를 함께 사용한다. MSW는 행사 구독과 고지서 기록·ID를 모두 초기화하고 이전 세션에서 누락된 필드를 복원한다.
- Figma v2의 문서 상태 카드가 기존 작은 로더를 사용하지 않아 해당 변경을 제외한다. 첨부·최근 기록 공통 UI와 알림 스위치의 터치·접근성 변경은 유지한다.
- `npm run check`는 Vitest 31개 파일 239개 테스트와 프로덕션 빌드를 포함해 통과한다. Vite의 500 kB 초과 청크 경고가 표시된다.
- Chrome 에뮬레이션과 로컬 MSW로 360×800·390×844·400×799와 네 언어를 조합한 12개 환경의 168개 상태를 확인한다. 고지서 업로드·결과·최근 기록·알림, 관련 안내에서 홈 체크리스트로 이동, 선택 항목 펼침·포커스와 삭제된 항목 404를 검증한다.
- 행사 구독과 고지서 기록이 이전 형식의 목업 세션을 읽은 뒤 함께 생성되고, 새로고침 후 함께 복원되며, 고지서 삭제가 행사 구독에 영향을 주지 않음을 확인한다. 실기기 및 실제 BE·Gemini는 미검증이다.
