# 웰컴시흥 하단바 아이콘

- 작성일: 2026-11-27

## 목적

회원 화면의 하단바에서 메뉴별 기능을 아이콘으로 구분할 수 있게 한다.

## 핵심 요청

하단바의 다섯 메뉴에 단순한 모양의 아이콘을 적용한다.

## 선택과 이유

| 검토한 방법                  | 선택 | 이유                                                                   |
| ---------------------------- | ---- | ---------------------------------------------------------------------- |
| 공통 선 아이콘 컴포넌트 확장 | 채택 | 기존 20px 크기와 색상 상속을 활용하고 별도 의존성 없이 구현할 수 있다. |

## 반영 내용

- 홈·생활 달력·생활 수칙·질문·내 정보에 각각 집·달력·책·말풍선·사람 아이콘을 적용한다.
- 메뉴의 상태별 색상을 아이콘에 상속하고 접근성 이름은 기존 메뉴 문구를 사용한다.

## 검증

| 확인 항목     | 방법                     | 결과                                                                                                    |
| ------------- | ------------------------ | ------------------------------------------------------------------------------------------------------- |
| FE 전체 검사  | `npm run check`          | 타입·린트·형식 검사 및 빌드 통과, Vitest 227개 테스트 통과                                              |
| 모바일 하단바 | 390×844 Chrome, 목업 API | 다섯 아이콘, 탭 이동, 강조 색상 및 4개 언어 메뉴 문구를 확인한다.                                       |
| 키보드 조작   | 390×844 Chrome, 목업 API | 최초 실행에서 Tab과 Enter로 달력 이동을 확인한다. 반복 실행에서 포커스 동작이 일관되게 재현되지 않았다. |

## 2026-11-27 하단바 문구 변경

- 사용자 결정에 따라 하단바의 생활 수칙은 생활 안내로, 질문은 챗봇으로 바꾼다.
- 네 언어의 `nav.rules`와 `nav.chat`에 새 문구를 적용한다.
- 390×844 Chrome 목업에서 네 언어의 하단바 문구를 확인한다.

## 2026-11-27 화면 및 연결 문구 통일

- 기존 작업 브랜치를 최신 로컬 `main`인 `f47443a`로 갱신한다. 하단바의 달력 아이콘에는 공통 달력 아이콘을 재사용한다.
- 생활 달력, 생활 안내, 챗봇의 화면 제목과 기능을 가리키는 도움말·검색 문구·버튼은 하단바와 같은 번역 키를 참조한다. 분야명과 개별 글 제목은 각 화면의 내용을 표시한다.
- 390×844 Chrome 목업에서 한국어·영어·중국어·베트남어로 세 화면의 제목, 생활 안내·행사·체크리스트의 챗봇 연결 문구, 행사의 생활 달력 저장 버튼을 확인한다.
- `npm run check`로 타입·린트·형식 검사, 테스트 299개 및 빌드 통과를 확인한다.
