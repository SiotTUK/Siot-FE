# 생활 달력 일정 상세·D-day·다음 할 일·고지서 세금 상세 연결

- 작성일: 2026-11-27
- 관련 이슈 / PR: #34, 선행 PR #86(세금 상세), BE SiotTUK/Siot-BE#28(연간 일정 개인 일정), BE 브랜치 `feat/bill-tax-detail-link`(고지서 세금 상세 연결, 미푸시·PR 미생성)

## 목적

#34의 남은 할 일 가운데 시안 v2에 있는 것을 마무리한다. 일정 D-day 배지, 공식 안내 링크, 일반 일정 상세 화면, 빈 달의 "다음 할 일", 고지서 번역 결과의 세금 상세 연결이다.

## 핵심 요청

- PR #86 반영 후 열린 이슈(#34·#50)를 코드로 마무리한다. 이슈별로 브랜치를 나누고 로컬 커밋까지 한다. 푸시와 PR은 따로 확인받는다.
- 고지서 번역 응답에 세금 종류·세금 일정 ID가 없어서 BE에 먼저 구현한다(사용자 결정). 사용자는 BE에 이미 있을 것으로 봤으나, 확인해 보니 BE main·브랜치·열린 PR 어디에도 없었다.

## 선택과 이유

| 검토한 방법                                                         | 선택 | 이유                                                                                     |
| ------------------------------------------------------------------- | ---- | ---------------------------------------------------------------------------------------- |
| 일반 일정 상세를 세금 상세 화면과 같이 씀                           | 채택 | BE `GET /api/schedules/{id}`가 세금 상세와 같은 `TaxDetailResponse`를 준다               |
| 빈 달 다음 할 일: `GET /api/schedules/yearly`(그해, 없으면 다음 해) | 채택 | 연간 API가 개인 일정도 넣는다(BE #28). 월간을 달마다 부르는 것보다 요청이 적다           |
| 빈 달 다음 할 일: `GET /api/schedules/this-month`                   | 제외 | 이번 달·다음 달만 본다. 다른 달을 보고 있을 때 쓸 수 없다                                |
| 지난 일정에도 `기한 지남` 배지                                      | 제외 | 날짜가 이미 보이고, 지난 달 줄마다 붙으면 시끄럽다. D-day는 `dDay ≥ 0`만                 |
| 공식 안내 링크를 상세가 있는 줄에도 표시                            | 제외 | 상세 화면 아래에 링크가 있다. 상세가 없는 줄에만 `공식 안내 보기 ↗`                      |
| 고지서 → 세금 상세: FE가 세목 글자로 종류 추측                      | 제외 | FE는 BE 계약을 따른다. BE에 `taxKind`·`taxScheduleId`를 추가했다(사용자 결정)            |
| 고지서 → 세금 상세: 일정 ID가 없으면 종류로 회차 선택               | 채택 | 독촉장처럼 납기가 공통 일정 밖이면 ID가 없다. 생활 수칙과 같은 회차 규칙(`pickTaxRound`) |

## 반영 내용

- 일정 줄(생활 달력)
  - 오른쪽에 서버 `dDay` 배지(D-5·D-Day). `내 일정`·`확인 필요` 태그는 그 아래에 둔다.
  - 세금(`taxScheduleId`)은 `세금 상세 보기 ›`, 그 밖의 공통 일정(`scheduleId`)은 `자세히 보기 ›`.
  - 상세가 없는 줄은 `sourceUrl`이 http(s)일 때 `공식 안내 보기 ↗`.
- 일정 상세 `/calendar/schedules/:scheduleId` → `GET /api/schedules/{id}`. 세금 상세 화면 구성을 같이 쓰고, 제목·기간 라벨·404 문구·링크 문구만 다르다. 세금 상세의 납부 링크도 http(s)만 보인다.
- 빈 달 "다음 할 일 · {월}": 일정·행사가 모두 없는 달(날짜 미선택, `찜한 행사` 칩 제외)에 그 달 다음에 시작하는 첫 일정을 보인다.
- 고지서 번역 결과: BE `taxScheduleId`가 있으면 그 회차, 없으면 `taxKind`로 고른 회차의 `세금 상세 보기` 카드(`TaxDetailLink` 재사용). 둘 다 없거나 회차가 없으면 숨긴다.
- MSW: `/api/schedules/yearly`, `/api/schedules/{id}` 추가, 월간 일정에 `dDay`. 고지서 목업은 BE처럼 `taxKind: 'TAX_CAR'`, `taxScheduleId: null`(목업에 자동차세 공통 일정 없음).
- 4개 언어 문구: 일정 상세, 공식 안내 보기, 다음 할 일.
- BE(`feat/bill-tax-detail-link`, `47e0c17`): `BillTranslationResponse`에 `taxKind`(세목 → TAX_CAR·TAX_PROPERTY·TAX_RESIDENT)와 `taxScheduleId`(납기가 든 같은 종류의 공통 세금 일정)를 추가했다. 저장·조회 응답 때마다 다시 찾는다.
