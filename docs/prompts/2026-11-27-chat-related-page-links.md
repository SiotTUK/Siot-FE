# 챗봇 관련 화면 링크를 생활수칙·체크리스트·생활 변화 할 일까지 연결 (CB-10)

- 작성일: 2026-11-27
- 관련 이슈 / PR: [#45](https://github.com/SiotTUK/Siot-FE/issues/45) / PR 미생성

## 목적

챗봇 답변의 관련 화면(`relatedPages`) 중 `EVENT`만 링크가 되고 `RULE`·`CHECKLIST`·`LIFE_CHANGE_TASK`는 제목만 보였다. 선행 작업(BE 생활수칙 코드 통일 SiotTUK/Siot-BE#17, 체크리스트 상세 #30)이 들어와 나머지 유형도 해당 화면으로 연결한다.

## 핵심 요청

- #45 이슈의 할 일을 구현한다.

## 선택과 이유

| 검토한 방법                                                    | 선택 | 이유                                                                                                                                                                                                             |
| -------------------------------------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RULE` → `/rules/{code}`                                       | 채택 | BE 생활수칙 코드가 FE 슬러그와 같아졌다(#45 댓글). `isRuleCode`로 형식만 확인한다                                                                                                                                |
| `CHECKLIST` → `/home/checklist/{code}`                         | 채택 | 체크리스트 상세(#30). `CL-nn` 형식만 링크한다                                                                                                                                                                    |
| `LIFE_CHANGE_TASK` → 생활 변화 화면 `/home/life-changes/LC-0n` | 채택 | 체크리스트 상세는 회원의 현재 목록에 있는 항목만 찾아, 그 생활 변화를 등록하지 않은 회원에게는 '찾을 수 없음'이 된다. 생활 변화 화면은 등록했으면 할 일 목록, 아니면 날짜 선택을 보여 줘 늘 쓸 수 있다 (AI 판단) |
| `LIFE_CHANGE_TASK` → 체크리스트 상세 `/home/checklist/LC-0n-m` | 제외 | 위 이유                                                                                                                                                                                                          |
| 대화로 돌아가기: 공통 `chatBackPath(state)`                    | 채택 | 행사 상세에만 있던 `/chat/{id}` 검사를 `src/shared/lib/chat-back.ts`로 옮겨 생활수칙·체크리스트·생활 변화 화면이 같이 쓴다. 기존 `state.from` 방식 유지                                                          |

`LC-0n-m` → `LC-0n`: BE 시드의 `guide.life_change_code`가 앞 두 마디다(#45 댓글). 응답에 생활 변화 코드 필드는 없다.

## 반영 내용

- `related-pages.ts`: 유형별 경로. 형식이 맞지 않는 코드와 알 수 없는 유형은 링크 없이 제목만 보인다. 형식은 맞지만 BE에 없는 코드는 각 화면의 '찾을 수 없음'을 보여 준다.
- `src/shared/lib/chat-back.ts`: `state.from`이 `/chat/{id}`이면 그 경로를 돌려준다. 행사 상세(`eventDetailBackPath`)도 이 함수를 쓴다.
- 생활수칙 상세·카테고리·FAQ(`useRulesBack`): 대화에서 열면 ‹가 대화로 간다.
- 체크리스트 상세(`detailBackPath`): `state.back`(홈 화면)이 없고 대화에서 열었으면 대화로 간다.
- 생활 변화 할 일·선택 화면: 대화에서 열면 ‹ '뒤로'가 대화로 간다. 미등록이라 선택 화면으로 넘어갈 때와 날짜를 저장하고 할 일 화면으로 갈 때 `state`를 넘겨 대화로 돌아가는 길을 유지한다.
- MSW: 기본 답변의 관련 화면에 `LIFE_CHANGE_TASK`(`LC-01-1`)·`RULE`(`waste-food`) 추가.
- 테스트: 유형별 경로와 잘못된 코드, `chatBackPath`, 체크리스트 상세 뒤로 가기.

## 남은 작업

- 생활 변화 할 일 화면에서 할 일을 눌러 체크리스트 상세로 갔다가 돌아오면 할 일 화면의 ‹는 다시 홈으로 간다(기존 `state.back` 흐름). 필요하면 후속으로 대화 경로를 이어 준다.
