# 체크리스트 경고(CHK-08)를 BE warning으로 표시

- 작성일: 2026-11-27
- 관련 이슈 / PR: #50, 선행 PR #86(번역 준비 중), BE SiotTUK/Siot-BE#18·#28

## 목적

BE 체크리스트 응답의 CHK-08 경고(`warning`·`warningType`·`warningMessage`)를 화면에 반영한다. 지금은 상세에만 BE 문구가 나오고, 기한이 지난 항목은 FE 문구와 겹쳐 나온다. 할 일 줄과 홈 알림 줄은 경고를 보지 않는다.

## 핵심 요청

- PR #86 반영 후 열린 이슈(#34·#50)를 코드로 마무리한다. 이슈별로 브랜치를 나누고 로컬 커밋까지 한다. 푸시와 PR은 따로 확인받는다.
- 홈 상단 알림 줄은 BE 경고 항목을 먼저 띄우고, 없으면 지금처럼 30일 기준을 따른다(사용자 결정).
- 경고 문구는 BE `warningMessage`(4개 언어)를 그대로 쓴다(사용자 결정).

## 선택과 이유

| 검토한 방법                                | 선택 | 이유                                                                        |
| ------------------------------------------ | ---- | --------------------------------------------------------------------------- |
| 홈 알림: BE 경고 우선, 없으면 FE 30일 기준 | 채택 | 사용자 결정. 외국인등록·체류지 신고 경고가 세금 같은 가까운 기한보다 앞선다 |
| 홈 알림: BE 경고만                         | 제외 | 사용자 결정. 경고 없는 30일 이내 기한이 홈에서 빠진다                       |
| 문구: BE `warningMessage` 그대로           | 채택 | 사용자 결정. BE가 4개 언어로 준다                                           |
| 문구: `warningType`으로 FE 문구 선택       | 제외 | 사용자 결정                                                                 |
| 할 일 줄: 기한 초과도 경고 태그 추가       | 제외 | 빨간 `기한 지남` D-day 칩이 이미 있다. 그 밖의 경고에만 `마감 임박` 태그    |
| 완료·해당 없음 항목의 경고 숨김(FE)        | 채택 | BE는 완료한 CL-01·CL-02에도 `REGISTRATION_DUE`를 보낸다(BE 미수정)          |

## 반영 내용

- `features/checklist/checklist.ts`
  - `hasWarning`: `warning === true`이고 남은 항목(TODO·OVERDUE)일 때만 경고로 본다.
  - `warningText`: 경고 항목의 `warningMessage`.
  - `dueSoon`: 기한 초과가 아닌 경고(외국인등록 D-30, 체류지 변경 신고 D-7).
  - `pickDeadlineAlert`: 경고 항목 중 기한이 가장 가까운 것을 먼저 고르고, 없으면 30일 이내 가장 가까운 기한을 고른다. 홈 H1·H2 전환(`homeHero`)도 이 결과를 따른다.
- 체크리스트 상세: 경고 문구와 FE `checklist.overdue`가 겹치지 않게 하나만 보인다. 경고가 있으면 BE 문구, 없으면(예전 응답) 기한 초과일 때 FE 문구. 기한 초과는 빨간 안내, 그 밖은 주황 안내.
- 할 일 줄(홈·생활 변화): `dueSoon`이면 `마감 임박` 태그(4개 언어).
- MSW 체크리스트 목업: BE `ChecklistService`와 같은 규칙으로 `warning`·`warningType`·`warningMessage`(4개 언어)를 준다. 완료한 CL-01에도 경고를 주는 BE 동작도 따른다.
- 테스트: 경고 판별·문구·태그·홈 알림 우선순위.
