# 행사 카테고리 표시와 카테고리 필터 (EVE-10)

- 작성일: 2026-11-27
- 관련 이슈 / PR: [#37](https://github.com/SiotTUK/Siot-FE/issues/37) / PR 미생성

## 목적

BE `3194769`에서 행사 응답에 `category`·`categoryName`이 생기고 `GET /api/events`·`/api/events/calendar`에 `category` 필터가 생겼다. FE 타입·목업에 반영하고 행사 목록에서 카테고리를 표시·필터링한다.

## 핵심 요청

- #37 이슈의 할 일을 구현한다.
- 시안에 위치가 없는 카테고리 표시는 사용자가 '카드 메타 + 상세 태그'를 골랐다.
- 생활 달력의 카테고리 필터 UI는 사용자 선택에 따라 이번 범위에서 제외했다.

## 선택과 이유

| 검토한 방법                                 | 선택 | 이유                                                                                                                                                             |
| ------------------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 카테고리 값을 FE에 고정 (`eventCategories`) | 채택 | 목록 API가 없고, BE `EventCategory`는 출처 분류를 옮긴 5개 값이라 BE 배포 때만 바뀐다. 칩 이름은 BE `displayName`과 같은 문구를 4개 언어로 둔다 (AI 제안)        |
| 카테고리 목록 API를 BE에 요청               | 보류 | 값이 늘어나면 다시 검토한다                                                                                                                                      |
| 표시: 카드 메타 줄 앞 + 상세 태그 줄        | 채택 | 사용자 선택. 새 배지 없이 기존 요소에 텍스트만 더해 시안 변경을 줄인다                                                                                           |
| 표시: 상세에만 / 카드에 카테고리 배지 추가  | 제외 | 사용자 선택에 따라 제외                                                                                                                                          |
| 필터: 상태 칩 아래 별도 '분류' 칩 줄(pill)  | 채택 | Figma v2 목록 칩(전체·진행 중·곧 시작·무료·아이와 함께)에는 BE 카테고리가 없다. 기존 필터 영역과 '필터 초기화'에 묶어 #33 지역 필터와 같은 자리에 둔다 (AI 제안) |
| 생활 달력 카테고리 필터 UI                  | 제외 | 사용자 선택. `fetchEventCalendar`만 `category` 인자를 받게 해 둔다                                                                                               |
| 분류별 기본 이미지                          | 보류 | 디자인에서 받을 이미지 자산이 없다                                                                                                                               |

## 반영 내용

- `event-filters.ts`: `eventCategories`·`EventCategory`·`isEventCategory` 추가. 목록 필터에 `category`를 더해 URL `?category=`로 유지하고, 모르는 값은 버린다. 필터 초기화에 포함하고 `GET /api/events?category=`로 보낸다.
- `api.ts`: `EventSummary`·`EventDetail`·`EventCalendarItem`에 `category`·`categoryName` 추가. `fetchEventCalendar`에 선택 인자 `category` 추가(현재 화면에서는 쓰지 않음).
- 목록 필터: '분류' 칩 줄(전체 분류 + 5개). 행사 카드 메타 줄 앞에 `categoryName`, 상세 태그 줄 첫 칸에 `categoryName`(neutral 태그). 카테고리가 늘 있어 상세 태그 줄은 항상 표시된다.
- 4개 언어 문구: `events.filters.category`·`allCategories`, `events.categories.*`.
- MSW: 목업 행사에 카테고리 지정, `category` 필터(대소문자 무시)와 잘못된 값의 400 `INVALID_INPUT`을 BE `EventQueryService`와 같게 처리. 달력 응답에도 카테고리 포함.
- 테스트: 필터 파싱·URL·요청 쿼리·초기화, 목업 카테고리 필터.
