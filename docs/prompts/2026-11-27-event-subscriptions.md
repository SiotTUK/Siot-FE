# 행사 알림 신청과 행사 상세 보완

- 작성일 2026-11-27
- 관련 이슈 및 PR [FE #32](https://github.com/SiotTUK/Siot-FE/issues/32), [FE PR #25](https://github.com/SiotTUK/Siot-FE/pull/25), [BE PR #17](https://github.com/SiotTUK/Siot-BE/pull/17), [BE PR #28](https://github.com/SiotTUK/Siot-BE/pull/28)

## 목적

행사 상세와 추천 카드에서 알림을 신청·변경·해제하고, 일정 변경 알림에서 해당 행사 상세로 돌아오는 흐름을 완성한다. 행사 상세의 공유, 챗봇 질문 초안, 자동 번역 표시도 연결한다.

## 핵심 요청

BE 저장소에서 실제 요청·응답과 알림 동작을 확인하고 로컬 실제 서버로 연동한다. 사용자는 추천 카드에서 바로 설정하는 방식을 선택했다. 리뷰를 위해 PR 전체는 가급적 800줄 이하, 커밋 후보는 각각 100~300줄로 준비한다. 승인 후에만 커밋하거나 푸시한다.

## 선택과 이유

- 추천 카드의 알림 버튼을 누른 행사만 구독 상태를 조회한다. 카드 링크와 버튼을 독립적으로 조작할 수 있고, 상세와 회원별 구독 캐시를 공유한다.
- 서버에 저장된 알림 시점과 변경 결과를 표시하고, 저장 실패 시 화면의 선택값을 유지한다. 한국 시간 기준 이미 끝난 행사는 기존 구독을 해제할 수 있다.
- 행사 질문은 새 대화의 입력 초안으로 전달한다. 상세의 신청 링크는 BE가 유효한 URL을 제공할 때만 표시한다.

## 반영 내용

- 행사 구독 GET·POST·DELETE 연결, 상세 및 추천 카드의 공통 설정 UI, 네 언어 문구
- 공유 시트와 클립보드 복사·직접 복사, 챗봇 초안과 상세 복귀, 자동 번역 상태 표시
- 회원별 구독 목업과 API 계약·세션 전환·공유 테스트
