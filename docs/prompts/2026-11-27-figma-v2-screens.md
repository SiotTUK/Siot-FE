# 화면 전체를 Figma 시안 v2에 맞춤 (#49·#31)

- 작성일: 2026-11-27
- 관련 이슈 / PR: #49, #31 / PR 미생성
- 이전 기록: [2026-11-27-home-h1-h2.md](2026-11-27-home-h1-h2.md) (PR #82)

## 목적

#49(시안 v2와 다른 화면 배치)와 #31(맞춤 홈 보완)의 남은 항목을 처리한다. 기준은 Figma `design-system · 해로토로 v2`(456:2)이다.

## 핵심 요청

- #31과 #49를 완전히 해결한다.
- 사용자 결정 (작업 전 질문):
  - 글꼴: Pretendard 유지 (v2는 Noto Sans KR)
  - 도우미 화면: M08a 기준으로 헤더와 입력창을 통일
  - 할 일 이유 문구: BE `category`로 표시
  - 행사 ♥ 찜: 기존 행사 알림 구독 API에 연결

## 선택과 이유

| 검토한 방법                                                   | 선택      | 이유                                                                                                                                                                                  |
| ------------------------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 이유 문구 매핑 `FAMILY` → 자녀                                | 제외      | BE 시드(V2026_11_14_0430)에서 자녀 전학(LC-01-4)은 `EDUCATION`, `FAMILY`는 CL-08이다. `CAR` → 자차, `EDUCATION` → 자녀로 매핑하고, 차·입학 생활 변화 자체의 할 일에는 표시하지 않는다 |
| 행사 카드 ♥ 상태를 행사마다 구독 상태 API로 조회              | 제외      | 카드마다 요청이 생긴다. `GET /api/members/me/event-subscriptions?size=100` 한 번으로 찜한 행사 ID를 받는다                                                                            |
| 행사 상세의 알림 스위치 3개(신청 마감 전·24시간 전·일정 변경) | 일부 채택 | 구독은 알림 시점 하나(1·3·7일)만 가진다. 시점 선택과 "일정이 바뀌면 알려 드려요"(BE 수집 시 일정 변경 알림 확인)만 보이고, BE 지원이 없는 "신청 마감 전"은 뺀다                       |
| 생활 달력에 모든 행사 표시                                    | 제외      | v2 "찜하고 달력에 담기"에 맞춰 찜한 행사만 표시한다. 칩: 전체·할 일·찜한 행사                                                                                                         |
| 생활 변화 바텀 시트 유지                                      | 제외      | v2 F06a는 전체 화면이다. `/home/life-changes`(F06a)를 새로 만들고 시트를 지운다                                                                                                       |
| 홈 카드의 `해당 없음` 유지                                    | 제외      | v2 카드에 없다. 체크리스트 상세 화면으로 옮긴다                                                                                                                                       |
| 행사 캐러셀 마지막 "행사 전체 보기" 카드                      | 제외      | v2 시안에 없다                                                                                                                                                                        |
| H2 행사 제목 "이번 주 시흥 행사"                              | 보류      | 추천 API가 이번 주 행사만 주지 않는다. 기존 제목을 유지한다                                                                                                                           |
| 생활 수칙 "최근 바뀐 안내"                                    | 보류      | FE 정적 데이터는 모든 수칙이 같은 확인일이라 바뀐 항목을 알 수 없다. BE 데이터(#42) 필요                                                                                              |
| 도우미 사진 버튼·"고지서 사진 번역" 칩                        | 보류      | 고지서 번역(#28·#29) 미구현                                                                                                                                                           |
| 알림 설정의 체크박스 모양·"이메일로도 받기"                   | 보류      | 기존 스위치 유지. 이메일 수신 설정 API가 없다(#35·#72)                                                                                                                                |

## 반영 내용

- 디자인 토큰: v2 색(`Tint` #e3f3f7, `Ink` #1a1f27, `Canvas` #f5f7f6, `Error` #c7363f)을 앱 전체에 적용하고, 시작·회원가입 화면만 덮어쓰던 색을 지운다.
- M13: 공통 `StatusCard`·`EmptyState`. 불러오기 실패("연결이 잠깐 끊겼어요"/"내용을 불러오지 못했어요" · 다시 시도), 없는 페이지("페이지를 찾을 수 없어요" · 홈으로), 알림 없음.
- 홈 H1·H2:
  - H1 상단 파란 카드: 가장 가까운 마감, 진행 막대, 토로
  - H2: "다음 할 일 · 2027년 3월 / 지금 급한 할 일은 없어요"
  - 체크리스트: "나에게 필요한 할 일 N" 한 카드 안의 줄(체크박스·`이사` 칩·제목·"기한 문구 · 장소"·D-day), "생활 준비 (선택) N개 더 ›"
  - 생활 변화 카드: "요즘 무슨 일이 있나요?" / "이사 진행 중 · 할 일 N개"
  - 노란 서류 번역 카드(준비 중)
  - 순서: 상단 카드 → 상황 → 체크리스트 → 생활 변화 → 서류 → 행사
- 생활 변화:
  - F06a: 아이콘 라디오 목록, "언제였나요?", 할 일 보기
  - F06b: 진행 막대, 노란 "먼저 하세요" 카드(방법 보기), "함께 챙길 일"(이유 문구), 과태료 안내, [다른 생활 변화 등록][홈으로], 헤더 `수정`
- 행사:
  - 카드 세 가지(캐러셀·추천 큰 카드·목록 줄)와 ♥
  - 목록은 추천 큰 카드 한 장 + 1열 목록
  - 상세: 헤더 ♡·공유, 아이콘 사실 카드, 소개, "찜하면 알림도 받아요", 해로 메모, 글자 링크(원문 보기·신청하기·정보 오류 신고), [질문하기][♥ 찜하고 달력에 담기]
- 도우미:
  - 헤더 아이콘(기록·새 대화), 토로 소개와 답변 언어
  - 아바타 인사 말풍선, 테두리 추천 칩
  - 한 줄 입력과 둥근 전송 버튼
  - 답변: 질문 카드, "토로 · 웰컴시흥 도우미" 답변 카드, "출처 · …" 글자 링크, 관련 화면 전체 폭 버튼, 큰 평가 버튼 두 개, "답변을 찾고 있어요 · · ·"
- 생활 달력: 칩(전체·할 일·찜한 행사), 제목 옆 "‹ 2026년 11월 ›", "11월 일정 N개" 줄(날짜·요일·♥·찜 배지), 해로 메모.
- 알림: 제목 옆 `설정`, 해로 메모, 배지 "생활 마감 · 오늘", 빈 화면.
- 내 정보: 토로 메모, 행 순서(나의 상황·체류 만료일·알림 설정·입국일·체류 목적·거주 정보), "알림 설정 · 앱 · 이메일 ›".
- 목업: 찜한 행사 목록 핸들러, 생활 변화 할 일의 BE 시드 `category`.
- 공통 코드 영향:
  - `styles.css` 토큰 값
  - `QueryState` 오류 화면과 `InfiniteList` `empty` 타입(문자열 또는 노드)
  - `icons.tsx` 아이콘 추가
  - `screen-header.module.css` `position: relative`
  - `format.ts` `formatLongMonthDay` 추가
