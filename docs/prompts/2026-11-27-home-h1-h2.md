# 맞춤 홈 보완: 상황 `변경`·급한 할 일 없음(H2)·생활 변화 칩

- 작성일: 2026-11-27
- 관련 이슈 / PR: #31 / PR 미생성

## 목적

맞춤 홈을 Figma 시안 v2(`design-system · 해로토로 v2`, 456:2)의 H1·H2에 맞춘다. #31의 할 일 중 BE 변경 없이 할 수 있는 범위를 반영한다.

## 핵심 요청

- #31 작업 진행. 같은 날 이슈 본문을 v2 기준으로 갱신했고, 그 내용을 따른다.

## 선택과 이유

| 검토한 방법                                                    | 선택 | 이유                                                                                          |
| -------------------------------------------------------------- | ---- | --------------------------------------------------------------------------------------------- |
| H2 판단을 BE 필드로 받기                                       | 제외 | 지금 응답에 없음. 기존 홈 알림과 같은 기준(`pickDeadlineAlert`, 서버 `dDay` 30일 이하)을 쓴다 |
| "다음 할 일"을 FE가 기한으로 계산                              | 제외 | FE는 기한을 계산하지 않는다. 열린 항목 중 서버 `dDay`가 가장 작은 항목을 고른다               |
| 생활 변화 칩을 할 일 코드 앞부분(`LC-01-1` → `LC-01`)으로 표시 | 채택 | 응답에 분류·이유 필드가 없어도 v2 홈의 `이사` 칩을 만들 수 있다                               |
| "자차가 있어서 보여요" 같은 이유 문구                          | 보류 | BE 응답에 이유 필드가 없다. `category`(CAR 등)로 추정하지 않는다                              |
| 행사 캐러셀 마지막 "행사 전체 보기" 카드                       | 보류 | v2 시안에 없다. 디자이너 확인 필요                                                            |
| H2 행사 섹션 제목을 "이번 주 시흥 행사"로 변경                 | 보류 | 추천 API는 이번 주 행사만 주지 않는다. 문구와 데이터가 어긋나 기존 제목을 유지한다            |

## 반영 내용

- 상황 요약을 한 줄 카드로 바꾸고 오른쪽에 `변경 ›`(→ `/me`)를 둔다. 답을 고치면 기존 `useSaveOnboarding` 무효화로 요약·체크리스트가 갱신된다.
- H2(30일 안에 마감인 열린 할 일이 없음):
  - 알림 줄 대신 "다음 할 일 · 2027년 3월 / 지금 급한 할 일은 없어요" 카드를 보여 준다.
  - 행사 추천을 체크리스트 위로 올린다.
  - 체크리스트를 "다음 할 일" 카드 하나로 줄이고, `전체 보기` / `다음 할 일만 보기`로 전환한다.
  - 다음 할 일이 없으면 전체 목록을 그대로 보여 준다.
- 생활 변화 할 일 카드 태그 줄에 `이사` 같은 칩을 붙인다. 생활 변화 화면에서는 모든 카드가 같은 칩이라 숨긴다.
- 4개 언어 문구 추가, `formatYearMonth` 추가.
- 공통 코드 영향: `src/shared/i18n/format.ts`에 함수 추가(기존 함수 변경 없음), `ChecklistCard`에 `showLifeChange` 선택 속성 추가.
