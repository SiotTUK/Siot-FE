# 알림 수신 이메일 정책 결정 (NTF-09·M-11)

- 작성일: 2026-11-27
- 관련 이슈 / PR: [#72](https://github.com/SiotTUK/Siot-FE/issues/72) / PR 미생성

## 목적

#72는 명세가 내 정보에서 알림 이메일을 선택적으로 등록·인증·변경·삭제하도록 한다고 보았지만, 현재 앱은 가입 이메일 하나로 로그인·비밀번호 재설정·알림 발송을 처리한다. 주소 역할과 인증 흐름, 수신 토글과의 범위를 정하고 화면에 반영한다.

## 핵심 요청

- #72 이슈를 기준으로 정책을 정하고 코드에 반영한다.
- 사용자는 AI가 제시한 세 가지 안 중 '단일 주소 유지'를 선택했다.

## 선택과 이유

| 검토한 방법                                                             | 선택 | 이유                                                                                        |
| ----------------------------------------------------------------------- | ---- | ------------------------------------------------------------------------------------------- |
| 단일 주소 유지 (가입 이메일 = 알림 수신 주소)                           | 채택 | 사용자 선택. BE 동작이 이미 이 정책과 일치해 스키마·API 변경 없이 화면 안내만 보강하면 된다 |
| 별도 알림 주소 추가 (`notificationEmail` 필드, 등록·인증·변경·삭제 API) | 제외 | 사용자 선택에 따라 제외. BE 스키마·API·FE 화면을 새로 만들어야 한다                         |
| 가입 이메일 변경 허용 (재인증 후 로그인 ID 변경)                        | 제외 | 사용자 선택에 따라 제외                                                                     |

## 정책

| 항목             | 결정                                                                                                                              |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 주소 수          | 회원당 가입 이메일 하나. 별도 알림 수신 주소는 두지 않는다                                                                        |
| 주소 역할        | 로그인 ID, 비밀번호 재설정(M-11) 메일, 알림(NTF-05) 메일을 모두 가입 이메일로 보낸다                                              |
| 등록             | 회원가입 때 인증한 가입 이메일이 곧 수신 주소다. 별도 등록·별도 동의 절차는 없다                                                  |
| 변경·삭제        | 지원하지 않는다. 주소를 바꾸려면 탈퇴 후 새 이메일로 가입한다(M-06)                                                               |
| 인증 코드        | 기존 규칙 유지: 10분 유효, 5회 틀리면 폐기, 재발송 1분 1회·하루 10회                                                              |
| 기존 미인증 회원 | 내 정보의 NTF-09 인증 폼으로 가입 이메일을 인증한다. 인증 전에는 알림 메일과 비밀번호 재설정 메일을 받지 않는다(인앱 알림은 받음) |
| 수신 거부        | 주소 단위 수신 거부는 없다. 알림 종류별 이메일 수신은 알림 설정의 토글(#35·#47, `emailEnabled`)로 끈다                            |

BE 확인 결과(Siot-BE `main`):

- `NotificationDispatcher`는 `hasVerifiedEmail()`인 회원에게만 `user.getEmail()`로 알림 메일을 보내고, 종류별 `emailEnabled=false`이면 건너뛴다.
- `PasswordResetService`는 인증된 가입 이메일에만 재설정 링크를 보낸다.
- 따라서 BE 변경은 필요 없다.

## 반영 내용

- 내 정보(M10) 이메일 아래에 이 주소의 용도를 안내한다. 인증 회원은 '알림 메일과 비밀번호 재설정 메일이 이 주소로 가요', 미인증 회원은 '인증하면 이 주소로 … 받을 수 있어요'를 표시한다. 4개 언어 문구를 추가했다.
- 변경 파일: `src/pages/me/me-page.tsx`, `src/pages/me/messages.ts`, `src/pages/me/me.module.css`
