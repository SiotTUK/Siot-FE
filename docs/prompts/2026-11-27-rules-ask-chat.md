# 생활수칙에서 챗봇에 질문하고 현재 대화로 다시 열기

- 작성일: 2026-11-27
- 관련 이슈 / PR: #69 / PR 미생성

## 목적

생활수칙 상세에는 챗봇 질문 진입점이 없고, 질문 탭(`/chat`)은 매번 새 대화를 열어 같은 방문에서 하던 대화를 이어가기 어려웠다. 생활수칙에서 질문 초안을 채워 챗봇을 열고, 질문 탭으로 이번 방문의 현재 대화를 다시 열게 한다.

## 핵심 요청

- 이슈 #69 해결과 PR 생성 요청. 범위는 이슈 본문을 따른다. 체크리스트 진입점은 이슈대로 #30 이후로 남긴다.

## 선택과 이유

| 검토한 방법                                                                 | 선택 | 이유                                                                                                            |
| --------------------------------------------------------------------------- | ---- | --------------------------------------------------------------------------------------------------------------- |
| 행사 전용 상태(`eventQuestionId`·`eventQuestionDraft`)를 공통 상태로 일반화 | 채택 | 행사·생활수칙(이후 체크리스트)이 같은 초안·복귀 동작을 쓴다. `chatTopic`·`chatDraft`로 통일하고 행사도 옮겼다   |
| 현재 대화를 sessionStorage에 회원 id와 함께 저장                            | 채택 | "같은 방문"을 탭 단위로 본다. 탭을 닫으면 사라지고, 회원 id가 다르면 무시해 다른 계정이 이전 대화를 열지 않는다 |
| 하단 탭 링크를 바꾸는 대신 `/chat`(초안 없음)에서 현재 대화로 이동          | 채택 | 챗봇 화면은 하단 탭 밖에 있고, 질문 탭·기록 화면 복귀 등 `/chat`으로 오는 모든 일반 진입에 같은 규칙이 적용된다 |
| 상세에서 들어온 초안은 새 대화로 연다                                       | 채택 | 이슈의 "해당 진입의 맥락 유지". 초안과 뒤로 가기(상세 복귀)가 그 진입에 묶인다                                  |

## 반영 내용

- `features/chat/chat-entry.ts`: 진입 상태 생성·검증(행사 id, 생활수칙 코드 형식), 뒤로 가기 경로, 현재 대화 저장·조회·삭제
- 챗봇 화면: 초안 없는 `/chat`은 현재 대화로 이동, 대화를 열면 현재 대화로 기억, 없는 대화(404)는 잊음, 대화 생성 후에도 상세 복귀 유지
- 현재 대화를 잊는 시점: 새 대화(챗봇·기록 화면), 해당 대화 삭제, 로그인·로그아웃·탈퇴·세션 만료
- 생활수칙 상세 하단에 `이 내용 질문하기`(4개 언어 초안)
- 행사 상세 질문 버튼을 공통 진입 상태로 전환
