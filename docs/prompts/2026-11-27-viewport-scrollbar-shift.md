# 홈 메뉴 전환 시 화면 위치 이동

- 작성일: 2026-11-27
- 관련 이슈 / PR: 미생성

## 목적

홈에서 생활 달력이나 챗봇을 열 때 중앙 앱 프레임이 오른쪽으로 움직이는 현상을 확인하고 수정한다.

## 핵심 요청

두 메뉴의 화면 전환에서 가로 이동이 발생하는지 재현하고 원인을 확인한다.

## 선택과 이유

Chrome의 1280×900 뷰포트에서 홈의 세로 스크롤바가 사라질 때 프레임의 왼쪽 좌표가 392.5px에서 400px로 바뀌었다. 중앙 정렬 프레임을 사용하는 481px 이상에서 문서 양쪽에 스크롤바 공간을 확보해 페이지 높이와 무관하게 중앙 위치를 유지하는 방식을 선택한다.

## 반영 내용

`src/styles.css`의 문서 루트에 `scrollbar-gutter: stable both-edges`를 적용한다. 원격 `main`의 하단 메뉴 아이콘 변경을 반영한 뒤 재검증한다.

## 검증

| 확인 항목     | 방법                                                                     | 결과                                   |
| ------------- | ------------------------------------------------------------------------ | -------------------------------------- |
| 데스크톱 전환 | Chrome 목업 1280×900 및 481×900에서 프레임 위치와 너비 측정              | 홈·생활 달력·챗봇의 위치와 너비가 동일 |
| 모바일 전환   | Chrome 모바일 에뮬레이션 390×844 및 320×844, 한국어·영어·중국어·베트남어 | 전환 시 프레임 이동 및 가로 넘침 없음  |
| 달력 상태     | 1280×900 및 390×844에서 지연, 오류, 빈 응답을 주입하고 다시 시도         | 각 상태에서 프레임 위치와 너비가 동일  |

모바일 390×844 목업 화면을 캡처한다. [생활 달력](assets/2026-11-27-viewport-scrollbar-calendar.png), [챗봇](assets/2026-11-27-viewport-scrollbar-chat.png).
