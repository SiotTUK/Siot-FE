# 관리자 화면 개선: 항목 고르기, 관리자 우선 정렬, 챗봇 답변 검색

- 작성일: 2026-11-28
- 관련 이슈 / PR: 이슈 미생성 / FE PR 미생성, BE SiotTUK/Siot-BE#41

## 목적

관리자 화면 세 곳의 불편을 고친다.

- 체크리스트 문구: 항목 코드를 외워서 입력해야 했다.
- 회원 권한: 가입 최신순이라 관리자가 목록에 흩어져 있었다.
- 챗봇 답변 검토: 특정 답변을 찾을 방법이 없었다.

## 핵심 요청

- 체크리스트 문구 화면에서 이미 있는 항목 목록을 보여 주고, 목록에서 골라 수정하게 한다.
- 회원 권한 목록에서 관리자가 맨 위에 오게 한다.
- 챗봇 답변 검토에 번호와 문구 검색을 넣는다.
- 후속 결정: 검색의 '아이디'는 검토 항목 번호(답변 messageId)로 한다. 세 가지 모두 BE 변경이 필요해 BE·FE PR을 각각 올린다.

## 선택과 이유

| 검토한 방법                                                                        | 선택                              | 이유                                                                                               |
| ---------------------------------------------------------------------------------- | --------------------------------- | -------------------------------------------------------------------------------------------------- |
| 항목 목록: FE에서 생활수칙·체크리스트 API를 모아 만들기 vs BE 관리자 목록 API 추가 | BE API 채택                       | 회원 체크리스트 API는 그 회원에게 해당하는 항목만 주므로 전체 목록을 만들 수 없다                  |
| 관리자 우선 정렬: FE 정렬 vs BE 쿼리 정렬                                          | BE 정렬 채택                      | 목록이 페이지 단위라 FE에서 정렬하면 보고 있는 페이지 안에서만 정렬된다                            |
| 검색 '아이디': 검토 항목 번호 / 회원 이메일 / 회원 번호                            | 검토 항목 번호 채택 (사용자 결정) | BE 검토 API는 회원 신원을 일부러 빼고 있어 이메일·회원 번호로 찾으려면 개인정보 정책을 바꿔야 한다 |
| 번호·문구: 입력 칸 하나 vs 두 개                                                   | 두 칸 채택                        | "30000원"처럼 숫자로 된 문구 검색과 번호 검색이 섞이지 않게 한다                                   |
| 목록을 못 불러올 때                                                                | 코드 직접 입력으로 대체           | 목록 API가 실패해도 기존처럼 코드로 수정할 수 있다                                                 |

## 반영 내용

- 체크리스트 문구: 항목 종류(전체·체크리스트·생활 변화 할 일·생활수칙)와 항목 선택("CL-01 · 외국인등록")으로 바꿨다. `?code=`로 열면 그 항목이 선택돼 있고, 목록에 없는 코드도 선택지로 남긴다. 목록을 못 불러오면 오류와 코드 입력 칸을 보여 준다.
- 회원 권한: 정렬은 BE가 하고, 화면 주석과 MSW 목업 정렬만 맞췄다.
- 챗봇 답변 검토: 답변 번호(`#32`·`32`)와 문구 검색 칸을 추가하고 카드에 `#번호`를 표시한다. 문구는 질문·답변·의견에서 찾는다(BE의 가린 문구 기준, 100자 이하).
- API: `fetchGuides`(`GET /api/admin/guides`), `fetchReviews`에 `messageId`·`keyword`.
- MSW: 항목 목록, 관리자 우선 정렬, 검토 번호·문구 검색.
