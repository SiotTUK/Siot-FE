# 관리자 첫 화면 메뉴를 자주 쓰는 순서로 정렬

- 작성일: 2026-11-28
- 관련 이슈 / PR: 이슈 미생성 / SiotTUK/Siot-FE#123

## 목적

관리자 첫 화면(`/admin`) 메뉴가 기능을 만든 순서대로 놓여 있어, 매일 처리할 메뉴(오류 신고)가 맨 아래에 있었다.

## 핵심 요청

- 관리자 메뉴의 우선순위를 AI가 판단해 자주 쓰는 기능을 위로 올린다.

## 선택과 이유

| 순서 | 메뉴            | 이유 (AI 판단, 사용 기록 근거 아님)                     |
| ---- | --------------- | ------------------------------------------------------- |
| 1    | 오류 신고       | 회원 신고가 매일 쌓이는 처리 대기 목록                  |
| 2    | 챗봇 답변 검토  | 안 됐어요 · 자료 없음 답변이 매일 쌓이는 처리 대기 목록 |
| 3    | 행사            | 수집 결과 확인과 직접 등록 · 수정이 잦음                |
| 4    | 생활수칙        | 한국어 · 번역 · 출처를 자주 고침                        |
| 5    | 체크리스트 문구 | 문구 수정 빈도가 생활수칙보다 낮음                      |
| 6    | 챗봇 근거 문서  | PDF 새 버전을 올릴 때만 씀                              |
| 7    | 회원 권한       | 관리자를 지정할 때만 씀                                 |

## 반영 내용

- `src/pages/admin/admin-pages.tsx`의 메뉴 목록 순서만 바꿨다. 경로 · 문구 · 권한은 그대로다.
