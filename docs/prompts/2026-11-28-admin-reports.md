# 관리자 오류 신고 처리 화면 (ADM-07)

- 작성일: 2026-11-28
- 관련 이슈 / PR: SiotTUK/Siot-FE#39 / SiotTUK/Siot-FE#118

## 목적

회원이 보낸 콘텐츠 오류 신고(COM-01)를 관리자가 확인하고 처리할 화면이 없었다. BE `AdminReportController`의 목록·단건·처리 API에 맞춰 `/admin/reports` 화면을 만든다.

## 핵심 요청

- 이슈 #39를 가져와 구현한다.
- 후속: 목업에서 체크리스트 코드(`CL-…`)로 신고하면 404가 나는 것이 BE에서도 생기는지 확인한다.
- 후속: 구현을 PR로 올린다.

## 선택과 이유

| 검토한 방법                                                               | 선택           | 이유                                                                                                                                   |
| ------------------------------------------------------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 목록 카드에서 바로 처리(챗봇 답변 검토 방식) vs 목록 → 단건 화면에서 처리 | 단건 화면 채택 | 이슈 할 일에 단건 화면이 있고, 상세 설명·메모가 길어 카드에 넣기 어렵다                                                                |
| 목록 첫 상태 필터: 전체 vs 접수                                           | 접수 채택      | 처리할 신고부터 보이게 한다. 전체로 바꿀 수 있다                                                                                       |
| 신고 대상 이동 화면                                                       | 종류별 연결    | 행사 → #40 행사 수정, 생활수칙 → 생활수칙 수정, 체크리스트·생활 변화 할 일 → 체크리스트 문구(`?code=`). 대상이 삭제되면 링크 없이 안내 |
| 목업 `POST /api/reports` 고정 응답 유지 vs 신고 저장                      | 저장 채택      | 회원 신고가 관리자 목록에 나타나는 흐름을 목업에서도 확인할 수 있다                                                                    |

## 반영 내용

- `report-api.ts`: `ContentReportResponse` 타입, 목록(`status`·`page`)·단건·처리 요청, 대상 화면 주소(`reportTargetPath`).
- `use-admin-reports.ts`: TanStack Query 훅. 처리 후 신고 목록·단건을 다시 불러온다.
- `ui/report-list.tsx`: 목록(상태 필터, 더 보기)과 단건(대상 제목 스냅샷, 문제 문구, 사유, 상세 설명, 화면 언어, 접수 시각, 신고자 회원 번호, 대상 열기)과 처리 폼(상태 4가지, 메모 2000자, 비우면 지움).
- 신고자는 BE 응답 그대로 회원 번호만 표시한다. 이메일 등은 BE가 보내지 않는다.
- 관리자 메뉴·라우트(`/admin/reports`, `/admin/reports/:reportId`), 한국어 문구, `CONTENT_REPORT_NOT_FOUND` 오류 문구.
- MSW: `handlers/admin-reports.ts`(목록·단건·처리, 예시 3건), 회원 신고를 관리자 목업에 저장. 기존 `rule-report.test.ts`가 고정 `reportId: 1`을 기대하던 부분을 수정했다.
