# 관리자 생활수칙 편집을 생활수칙 화면 하나로 합치기

- 작성일: 2026-11-28
- 관련 이슈 / PR: 이슈 미생성 / SiotTUK/Siot-FE#121 (#120은 base를 #119 브랜치로 잘못 잡아 main에 들어가지 않음, 선행: SiotTUK/Siot-FE#119)

## 목적

생활수칙을 '생활수칙' 화면과 '체크리스트 문구' 화면 두 곳에서 고칠 수 있어 기능이 겹치고, 출처 링크가 어긋날 수 있었다.

- 체크리스트 문구 화면에서 출처 링크를 바꾸면 대표 링크(`guide.source_url`) 하나만 바뀌고, 생활수칙 화면의 출처 목록은 그대로 남는다.
- 체크리스트 문구 화면의 한국어 폼에는 생활수칙의 안내 문장·시기 칸이 없다.

## 핵심 요청

- 관리자 화면의 중복 기능을 하나로 합치거나 한쪽을 지운다. 바꾸기 전에 사용자 판단을 받는다.
- 사용자 결정: 생활수칙은 생활수칙 화면으로 합친다. 오류 신고와 챗봇 답변 검토는 데이터가 달라 따로 둔다.

## 선택과 이유

| 검토한 방법                                                     | 선택               | 이유                                                                                                                        |
| --------------------------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 생활수칙 화면에 번역까지 넣고 체크리스트 문구에서 생활수칙 제외 | 채택 (사용자 결정) | 생활수칙 한 건을 한 화면에서 고친다. 두 화면이 다루는 항목이 겹치지 않는다                                                  |
| 체크리스트 문구에서 생활수칙은 번역만 고치게 하기               | 제외 (사용자 결정) | 화면이 두 개로 남는다                                                                                                       |
| 그대로 두기                                                     | 제외 (사용자 결정) | 출처 링크가 어긋나는 문제가 남는다                                                                                          |
| 오류 신고와 챗봇 답변 검토를 한 메뉴로 합치기                   | 제외 (사용자 결정) | 처리 대상과 필터가 다르다                                                                                                   |
| BE API 변경                                                     | 하지 않음          | 번역 저장은 기존 `PUT /api/admin/guides/{code}/translations/{language}`가 생활수칙 칸(`points`·`when`·`contact`)까지 받는다 |

## 반영 내용

- 생활수칙 수정 화면: "언어별 문구 검토 · 수정" 버튼(체크리스트 문구 화면으로 이동)을 없애고, 같은 화면 아래에 번역 섹션(영어·중국어·베트남어)을 넣었다.
  - 칸: 제목, 요약, 안내 문장(한 줄에 하나), 시기, 장소, 수수료, 안 하면, 근거 법령, 문의, "변경됨" 표시
  - 자동 번역인지 사람이 확인한 번역인지 표시하고, 저장하면 사람이 확인한 번역이 된다(BE 동작)
  - PUT은 공통 칸을 모두 바꾸므로, 폼에 없는 본문·배지·준비물·출처 이름은 저장된 값을 그대로 보낸다
- 체크리스트 문구 화면: 항목 종류에서 생활수칙을 빼고, 목록도 체크리스트·생활 변화 할 일만 보여 준다. 링크(`?code=`)나 직접 입력으로 생활수칙 코드를 열면 "생활수칙 화면에서 열기" 안내만 보여 준다.
- 메뉴 설명: "체크리스트 · 생활 변화 할 일 문구를 언어별로 수정"
