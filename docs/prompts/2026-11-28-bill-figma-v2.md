# 고지서 번역 화면 모양을 Figma v2에 맞춤

- 작성일: 2026-11-28
- 관련 이슈 / PR: #115. 이전 작업 #28·#29

## 목적

고지서 번역 화면(M11a 올리기, M11b 번역 중, M11c 번역 결과, M11d 읽기 실패)과 챗봇 안 고지서 카드(M08d)의 모양을 해로토로 v2 Figma에 맞춘다. 주황 카드와 짙은 청록 버튼을 브랜드 파랑·연파랑·연노랑으로 바꾼다. 업로드 흐름, 동의, 알림 설정, 저장·삭제 같은 기존 동작 코드는 바꾸지 않는다.

## 핵심 요청

- 요약: 사용자가 고지서 번역 화면 디자인을 Figma와 비교해 달라고 했고, AI가 차이를 정리했다. 사용자가 직접 고치기로 하고 다섯 화면을 한 PR로, 개인정보 안내는 한 줄에 자세히 보기를 붙이기로 했다.
- 후속: 사용자가 기존 기능 코드는 건드리지 말고 디자인만 고치라고 했다.

## 선택과 이유

| 검토한 방법                                           | 선택 | 이유                                                                                 |
| ----------------------------------------------------- | ---- | ------------------------------------------------------------------------------------ |
| Figma처럼 7일 전·1일 전 알림 스위치 두 개             | 제외 | 서버 알림 설정이 하나(두 알림 함께)다. 동작을 바꾸지 않으려고 스위치 하나를 유지했다 |
| 결과 화면 "원문 보기"·"2기분" 칩·문의 줄, "전체 ›"    | 제외 | 새 동작이나 새 데이터 표시가 필요하다. 디자인만 바꾸는 범위 밖                       |
| "원문과 함께 보기"를 용어 짝(납부기한 → Due date)으로 | 제외 | 서버는 원문 줄만 준다. 원문 줄을 같은 카드 모양으로 보여 준다                        |
| 개인정보 긴 안내 삭제(Figma 한 줄만)                  | 제외 | 외부 AI 전송·학습 고지는 남겨야 한다. 한 줄 + 펼쳐 보기로(사용자 결정)               |
| 해로 앉은 그림 새로 추가                              | 채택 | M11d 그림이 앱에 없다. Figma 원본(시흥시 공식 캐릭터)을 375px로 줄여 추가            |
| 문구를 Figma 문구로 교체                              | 제외 | 디자인만 바꾸는 범위라 기존 문구를 그대로 쓴다                                       |

## 반영 내용

- M11a: 연노랑 안내 카드(해로·토로 기대 앉은 그림), 점선 "사진 찍기" 카드(파란 원형 카메라), 아이콘이 있는 흰 "앨범에서 선택"·"PDF 파일", 자물쇠 한 줄 개인정보(펼치면 외부 AI 전송 안내), 전구 "잘 찍는 방법"(펼침), 최근 번역의 문서 아이콘.
- M11b: 큰 토로, 제목·소요 시간, 시계 아이콘 상태 카드, 토로 안내 카드(원본 저장 안 함), 연파랑 취소.
- M11c: 파란 요약 카드(문서 종류, 기한, D-day·발행 기관 칩, 토로), 왼쪽 이름·오른쪽 값 표, 빨간 ⓘ 확인 안내, 원문 줄 카드, "질문하기·완료 · 저장" 나란히.
- M11d: 앉은 해로, 문서 아이콘이 있는 실패 카드, 잘 찍는 방법 카드, "앨범에서 선택·다시 찍기".
- M08d: 금액·기한·납부 방법을 연노랑 상자에, "번역 결과 자세히 보기"를 연파랑으로, 확인 안내를 회색 한 줄로.
- 공용: 아이콘(사진·문서·자물쇠·전구·정보 등), `MascotImage`의 `toroStand`·`haeroSit`(Figma처럼 그림을 잘라 보여 줌). 기존 사용처 모양은 그대로다.
