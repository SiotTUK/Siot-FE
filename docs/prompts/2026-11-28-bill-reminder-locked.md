# 고지서 결과: 켤 수 없는 마감 알림을 흐리게, 기한 지남 칩을 빨갛게

- 작성일: 2026-11-28
- 관련 이슈 / PR: #141. 이전 작업 #115([2026-11-28-bill-figma-v2.md](2026-11-28-bill-figma-v2.md)), #28

## 목적

번역 결과 화면에서 기한이 지났거나 기한을 읽지 못한 고지서는 마감 알림을 켤 수 없다(서버 `reminderAvailable: false`, 화면도 스위치를 잠금). 그런데 잠긴 스위치가 꺼진 스위치와 거의 같아 보여 "알림 버튼이 눌리지 않는다"는 오해가 생겼다. 잠긴 상태와 기한이 지난 상태가 한눈에 보이게 한다. 잠그는 조건은 바꾸지 않는다.

## 핵심 요청

- 요약: 사용자가 사진을 찍은 뒤 결과 화면의 마감 알림 스위치가 눌리지 않는다고 알렸다. AI가 실제 서버에서 확인해 보니 고지서 납부 기한(2026-07-10)이 이미 지나 의도대로 잠긴 것이었다. 사용자가 잠긴 스위치를 흐리게 하고 기한 지남 표시를 붙이기로 했다.

## 선택과 이유

| 검토한 방법                                | 선택 | 이유                                                                                                          |
| ------------------------------------------ | ---- | ------------------------------------------------------------------------------------------------------------- |
| 공용 `SwitchField`의 잠김 모양을 더 흐리게 | 제외 | 알림 설정 화면도 저장하는 동안 스위치를 잠깐 잠근다. 공용을 바꾸면 그 화면에서 깜박인다. 공용에는 커서만 추가 |
| 고지서 결과의 알림 카드에서만 흐리게       | 채택 | 켤 수 없는 경우(`unavailable`)에만 스위치·알림 시각을 0.35로, 제목을 회색으로                                 |
| "기한 지남" 칩을 새로 추가                 | 제외 | 위 카드에 D-day 칩이 이미 "기한 지남"을 보여 준다. 같은 칩을 빨간 글자·연분홍 바탕으로 바꿨다                 |

## 반영 내용

- `bill-result.tsx`: 잠금 조건을 `unavailable` 변수로 뺐다(조건은 그대로). 알림 카드에 `data-locked`, 기한이 지난 D-day 칩에 `overdue` 모양.
- `bill.module.css`: 잠긴 알림 카드의 스위치·알림 시각 흐리게, 제목 회색. 기한 지남 칩 빨강.
- `switch-field.module.css`: 잠긴 스위치에 "누를 수 없음" 커서.
