# 생활 달력의 월 탐색과 일정 카드 정리

- 작성일: 2026-11-28
- 관련 이슈 / PR: 미생성
- 선행 기록: [디자인 토큰과 화면 타이포그래피 정리](2026-11-28-design-tokens.md)

## 목적

모바일 생활 달력에서 월 이동, 일정 상태, 안내 링크를 빠르게 찾을 수 있도록 배치한다. 첨부된 단일 일정 사례를 동일한 목업 응답으로 재현해 전후를 비교한다.

## 핵심 요청

생활 달력에서 읽기와 조작을 방해하는 요소를 찾아 수정하고, 같은 화면 크기와 데이터로 촬영한 전후 비교를 제공한다.

## 선택과 이유

| 검토한 방법                                                        | 선택 | 이유                                                                 |
| ------------------------------------------------------------------ | ---- | -------------------------------------------------------------------- |
| 오른쪽 배지 열을 유지                                              | 제외 | 390px 화면에서 제목과 설명의 열을 좁혀 날짜가 끊긴다.                |
| 제목 아래 상태 배치를 사용하고 왼쪽 날짜를 상단 정렬               | 채택 | 본문 폭을 확보한다. D-Day와 확인 상태는 배지 문구와 색으로 구분한다. |
| 월 이동을 달력 카드 상단에 배치하고 날짜 초기화를 결과 제목에 배치 | 채택 | 달력의 월 이동과 목록의 날짜 범위를 각각 해당 영역에서 조작한다.     |

## 반영 내용

- 화면 제목 26px, 월·일정 목록 섹션 제목 21px, 일정 항목 제목 16px에 공통 토큰을 사용한다.
- 왼쪽 날짜와 중복되는 하루 일정의 날짜는 접근 가능한 텍스트로 제공한다. 여러 날에 걸친 일정은 날짜 범위를 표시한다.
- 서버 설명의 날짜 문자열을 줄 중간에서 나누지 않고, 상세·공식 안내 링크에 밑줄과 44px 조작 높이를 적용한다.
- 날짜 전체 보기 버튼은 한국어·영어·중국어·베트남어 문구로 표시한다.

## 2026-11-28 후속 조정

- 직전 월 이동·날짜 초기화·카드 전체 재배치를 되돌리고, 기존 일정 목록 카드에 수정 범위를 한정한다.
- 일정 목록의 상세 설명을 제거한다. 상세 화면에서 제공하는 세금·일정 설명은 별도 흐름에서 확인한다.
- 체류기간 만료 카드에서는 D-Day 또는 D-n이 나올 때 확인 필요 배지를 생략한다. 연장 신청 시작일의 카운트다운과 만료 임박은 서로 다른 날짜를 가리킬 수 있어 확인 필요를 함께 표시한다. 카운트다운이 없는 확인 필요 상태, 내 일정, 찜도 각각 표시 조건을 따른다.
- 공식 안내 링크는 카드 오른쪽 아래에 연파랑 버튼 모양으로 배치한다. 내부 상세 링크는 기존 위치를 사용한다.
- 동일한 예시의 최종 [일정 카드](assets/2026-11-28-calendar-ui-revision-card.png)와 [전체 화면](assets/2026-11-28-calendar-ui-revision-screen.png)을 390×844 목업에서 촬영한다. 위 전후 캡처 표는 되돌린 시안의 기록이다.
- Chrome 목업에서 만료일 D-Day 단독, 연장 시작일 D-Day와 확인 필요, 카운트다운 없는 확인 필요, 내 일정 표시를 확인한다. 320px에서 네 언어의 화면 전체 가로 넘침이 없으며 공식 안내 링크는 44px 높이로 표시된다.
- 날짜 옆 세로선이 카드 안쪽 높이에 맞춰 늘어나도록 하고, 날짜와 요일을 세로 가운데에 정렬한다. 390px 목업에서 제목을 여러 줄로 늘려도 선 높이가 카드 내용과 일치하고 날짜가 가운데에 놓이는 것을 확인한다. [세로선 조정 캡처](assets/2026-11-28-calendar-ui-stretched-divider.png)

## 2026-11-28 행사 라인 조정

- 찜한 행사의 점선을 실선으로 바꾼다. 종료일이 시작일의 다음 달 같은 날 이상인 행사는 실제 시작일과 종료일에만 짧은 실선을 표시한다. 다음 달에 같은 날짜가 없으면 다음 달 말일을 기준으로 한다.
- 월간 목록과 날짜별 목록은 행사 전체 기간을 사용한다. 기간 중간 날짜에서 실선을 생략한 장기행사는 표시 줄을 사용하거나 숨은 표시 수를 늘리지 않는다.
- 일반 생활 일정은 하늘색, 세금은 민트색, 체류는 연보라색, 찜한 행사는 연노랑의 네 토큰을 사용한다.
- 백엔드 달력 조회는 월과 겹치는 행사의 원래 시작일·종료일을 반환하므로 프론트엔드에서 표시 범위를 계산한다.
- 390×844 Chrome 목업에서 [11월 단기행사 실선](assets/2026-11-28-calendar-event-lines-november.png), [12월 장기행사 종료 표시](assets/2026-11-28-calendar-event-lines-december.png)를 캡처한다. 7월 시작 표시, 11월 중간 날짜 목록에서 장기행사 조회, 320px 네 언어에서 가로 넘침 없음도 확인한다.
- `npm run check`를 통과한다. Vitest 605개가 통과하며, 정확히 한 달인 경우와 월말·윤년 경계를 포함한다.
