# 챗봇 첫 화면과 답변 머리를 Figma v2에 맞춤

- 작성일: 2026-11-28
- 관련 이슈 / PR: #112

## 목적

챗봇 화면의 토로 그림이 Figma보다 작다는 지적에서 시작해, 해로토로 v2 페이지의 "맞춤 안내와 질문" M08a(챗봇 · 처음 열기)·M08b(챗봇 · 답변)에 맞춰 첫 화면, 말풍선, 입력창, 답변 머리를 고친다. 답변 내용·출처·추천 질문 데이터는 서버 값을 그대로 쓴다.

## 핵심 요청

- 요약: 사용자가 챗봇의 토로 그림이 Figma보다 작다며 고쳐 달라고 했다.
- 후속: AI가 "주요 화면 UI" 페이지의 예전 M08a(서 있는 토로)에 맞췄는데, 사용자가 화면을 보고 Figma와 디자인이 다르다며 v2 화면을 보여 주고 링크를 줬다. v2 M08a·M08b 기준으로 다시 맞췄다.

## 선택과 이유

| 검토한 방법                                       | 선택 | 이유                                                                                          |
| ------------------------------------------------- | ---- | --------------------------------------------------------------------------------------------- |
| "주요 화면 UI" 페이지의 M08a(서 있는 토로 91×130) | 제외 | 사용자가 준 v2 화면(해로토로 v2 페이지)이 기준이다                                            |
| 토로 얼굴 그림을 새로 잘라 파일로 추가            | 제외 | Figma도 같은 `toro.png`를 250% 키워 잘라 쓴다. 같은 값을 CSS로 옮겨 그림 파일을 늘리지 않는다 |
| 언어 선택을 직접 만든 펼침 목록으로               | 제외 | 공용 `LanguageSelect`(기본 select)에 둥근 칩 모양만 더해 키보드·화면 낭독기 동작을 유지한다   |
| 추천 질문을 Figma 문구("쓰레기 버리는 요일" 등)로 | 제외 | 추천 질문은 서버에서 받는다. 모양만 맞춘다                                                    |

## 반영 내용

- 머리 제목: "챗봇" → "웰컴시흥 도우미"(`chat.title`, 4개 언어).
- 첫 화면: 72px 원형 토로 얼굴, "토로 · 웰컴시흥 도우미", 안내 문구, 언어 칩 "한국어로 답해요 ▾"(펼치면 각 언어로 "Answer in English" 등).
- 시간 표시: 화면을 연 시각을 "오늘 오후 2:10"처럼 보여 준다(`formatTime`, `chat.today`).
- 토로 말풍선: 32px 프로필 하나 아래로 인사 말풍선 두 개와 추천 칩을 묶었다. 말풍선은 왼쪽 위 4px, 나머지 18px 모서리, 본문 16px, 최대 너비 270px. 두 번째 인사에 "서류 사진을 보내면 번역도 해 줘요."를 붙였다(4개 언어, 리뷰 후 "고지서"로 바꿈).
- 추천 칩: 연한 파랑 바탕·파란 테두리, 고지서 칩은 카메라 아이콘.
- 입력창: 회색 둥근 입력칸(50px), 회색 원형 사진 버튼(카메라 아이콘), 파란 원형 전송 버튼.
- 답변 카드 머리: 28px 얼굴 프로필과 파란 "토로 · 웰컴시흥 도우미".
- 공용: `ToroAvatar`(72·32·28), `LanguageSelect`의 `pill` 모양과 `optionLabel`, `formatTime`. 기존 `LanguageSelect` 사용처 모양은 그대로다.

## 2026-11-28 후속: #112 리뷰 반영

- 요약: 사용자가 #112 리뷰를 요청했다. AI가 두 가지(새 대화를 시작해도 인사 위 시간이 처음 연 시각에 머묾, "서류 사진" 문구가 고지서 전용 기능보다 넓고 신분증 사진을 보내게 할 수 있음)를 찾았고, 사용자가 시간은 고치고 문구는 고지서로 바꾸기로 했다.
- 반영: 시간 줄을 `GreetingTime`으로 빼서 인사가 나타날 때마다 그 시각을 잡는다. 인사 문구를 "고지서 사진을 보내면 번역도 해 줘요."로 바꿨다(4개 언어, 칩 문구와 같은 단어).
- 검증: `npm run check` 통과. 목업에서 질문 후 페이지 시계를 2시간 앞당기고 "+"를 누르니 "오늘 오후 1:11" → "오늘 오후 3:11"로 바뀌었다.
