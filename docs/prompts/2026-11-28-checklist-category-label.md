# 체크리스트 상세에 분류 라벨 표시

- 작성일: 2026-11-28
- 관련 이슈 / PR: #143. #47(1·4번 중 체크리스트 카드 분류 라벨), #30·#31

## 목적

BE가 체크리스트·생활 변화 할 일에 보내는 분류 표시 이름(`categoryLabel`, 요청 언어)을 화면에 보여 준다. #47에서 남은 마지막 항목이다.

## 핵심 요청

- 요약: AI가 #47 진행을 정리하며 분류 라벨만 남았다고 했고, 사용자가 Figma를 보고 붙여 달라고 했다. AI가 찾아보니 Figma v2 체크리스트 화면에는 분류 라벨 자리가 없었다. 사용자가 체크리스트 상세 위 카드에 붙이기로 했다.

## 선택과 이유

| 검토한 방법                                 | 선택 | 이유                                                                |
| ------------------------------------------- | ---- | ------------------------------------------------------------------- |
| 상세 위 카드 태그 줄("필수 · D-day")에 추가 | 채택 | 기존 태그 모양 그대로라 디자인 변화가 가장 작다(사용자 결정)        |
| 홈 할 일 줄의 짧은 설명에도 추가            | 제외 | 줄이 길어지고 Figma 홈 줄보다 정보가 많아진다                       |
| FE에서 분류 코드를 문구로 바꿈              | 제외 | 서버가 요청 언어의 이름(`categoryLabel`)을 보낸다. 받은 그대로 쓴다 |

## 반영 내용

- `checklist-detail.tsx`: "필수" 태그 뒤에 `categoryLabel` 태그(없으면 표시 안 함).
- 목업: 외국인등록·체류기간 연장(`IMMIGRATION`, 출입국·체류), 건강보험 가입 확인(`HEALTH_INSURANCE`, 건강보험)에 BE와 같은 분류·이름을 넣었다.

## 2026-11-28 후속: "직장을 바꿀 때 절차 알아두기" 분류

- 요약: 사용자가 CL-07이 "출입국·체류"로 나오는 것을 보고 이직이 아니냐고 물었다. AI가 BE 초기 데이터를 확인했다. 분류는 생활 일이 아니라 담당 기관·법(출입국관리법 제21조 근무처 변경) 기준이고, 서버 분류에 "이직"은 없으며 "이직"은 생활 변화(LC-02) 칩으로 따로 붙는다. 분류는 BE 데이터라 FE·관리자 화면에서 바꿀 수 없다.
- 선택: 사용자가 지금 기준을 그대로 두기로 했다. 바꾸려면 BE 마이그레이션이 필요하다.
