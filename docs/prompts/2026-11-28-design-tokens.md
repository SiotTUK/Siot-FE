# 디자인 토큰과 화면 타이포그래피 정리

- 작성일: 2026-11-28
- 관련 이슈 / PR: 미생성

## 목적

홈에서 확인한 글자 크기와 색상을 공통 토큰으로 정의하고, 화면마다 달라지던 글자 위계를 정리한다.

## 핵심 요청

기존 화면보다 글자를 조금만 키운 시안을 적용한다. 브랜드 파랑과 행사 진행 상태 배지의 기존 색을 사용하고, 홈의 여유 상태 배너는 화면 배경과 구분되는 연하늘색을 사용한다.

## 선택과 이유

| 검토한 방법                                                         | 선택 | 이유                                                                                          |
| ------------------------------------------------------------------- | ---- | --------------------------------------------------------------------------------------------- |
| 화면 제목 28px, 카드 제목 18px, 본문 17px                           | 제외 | 홈 비교 시안에서 전체 크기가 과하다는 사용자 의견을 반영한다.                                 |
| 화면 제목 26px, 섹션 제목 21px, 카드 제목·본문 16px, 하단 메뉴 13px | 채택 | 사용자가 홈 비교 시안에서 확인한 크기다. 같은 크기의 제목과 본문은 굵기로 구분한다.           |
| 기존 브랜드 파랑과 흰색 행사 배지, 연하늘색 안내 배너               | 채택 | 사용자 선택을 반영한다. 안내 배너 배경은 화면 및 카드 배경과 구분하도록 별도 토큰을 정의한다. |

## 반영 내용

- `src/styles.css`에서 화면·섹션·하위 제목, 항목 제목, 본문, 버튼, 라벨, 보조 정보, 하단 메뉴의 글자 규격을 정의한다. 브라우저의 기본 글자 크기 설정을 따르도록 `rem`으로 지정한다.
- `#018EDA`를 브랜드와 상호작용에 사용한다. 행사 상태는 흰 배경과 브랜드색 글자를 사용하며, 홈의 여유 상태와 공통 정보 알림은 `#DDEFF8`을 사용한다.
- 공통 헤더·하단 메뉴·폼·버튼·선택 카드와 체크리스트·달력·행사·챗봇·생활 안내·고지서·관리자 화면의 개별 글자 크기를 공통 토큰으로 옮긴다.
- 아이콘 크기와 달력 칸의 공간 제약이 있는 초과 건수 표시는 화면별 크기를 사용한다.
