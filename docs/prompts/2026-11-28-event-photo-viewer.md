# 행사 상세 사진 크게 보기

- 작성일: 2026-11-28
- 관련 이슈 / PR: [Siot-FE #102](https://github.com/SiotTUK/Siot-FE/issues/102). PR은 미생성.

## 목적

행사 상세의 상단 사진은 영역에 맞춰 잘려 보인다. 사진을 눌러 전체를 따로 볼 수 있게 한다. 상단 사진 표시 방식, 목록 카드 썸네일, 사진이 없는 행사의 화면은 유지한다.

## 핵심 요청

- 상단 사진을 누르면 어두운 전체 화면에 사진 전체를 `object-fit: contain`으로 표시한다.
- 닫기 버튼, 배경 누르기, 휴대폰 뒤로 가기로 닫는다. 뒤로 가기로 상세 화면을 벗어나지 않는다.
- 상단 사진에는 크게 볼 수 있음을 알리는 작은 아이콘 하나만 붙인다.
- 확대·축소는 브라우저 기본 핀치 줌을 쓰고 막지 않는다. 별도 제스처 구현·라이브러리·여러 장 넘기기는 제외한다.
- 화면 문구는 기존 다국어 처리 방식을 따른다. 브랜치는 `feat/event-photo-viewer`로 지정한다.
- 첫 요청은 커밋 없이 바뀐 파일과 스크린샷을 보고하는 것이다. 후속 요청은 작업 기록, 스크린샷 정리, 커밋·push, PR 본문 작성이다. PR은 생성하지 않는다.

## 선택과 이유

아래 선택은 AI가 정한 것이다. 결과 보고 뒤 사용자가 마무리를 요청한다.

| 검토한 방법                                     | 선택 | 이유                                                                                            |
| ----------------------------------------------- | ---- | ----------------------------------------------------------------------------------------------- |
| 네이티브 `<dialog>`의 `showModal`               | 채택 | 기존 `Sheet`와 같은 방식이다. 모달 초점 처리와 Esc 입력을 브라우저에 맡긴다.                    |
| 열 때 방문 기록 추가, 닫을 때 한 단계 뒤로      | 채택 | 뒤로 가기 한 번이 사진만 닫는다. 라우터 `state`를 써서 상세의 `from`과 상단 뒤로 경로를 지킨다. |
| 여백 클릭을 `contain`의 실제 그림 영역으로 판정 | 채택 | `<img>`가 화면 전체를 차지해 클릭 대상만으로는 사진과 여백을 구분할 수 없다.                    |
| `<img>`를 원본 비율 크기로 두고 가운데 배치     | 제외 | 작은 사진이 화면에 맞게 커지지 않는다.                                                          |
| 사진을 불러온 뒤에만 버튼 표시                  | 채택 | 사진이 없거나 불러오지 못한 행사는 기존 화면과 같다.                                            |
| 배경 불투명도 92%                               | 제외 | 촬영 화면에서 뒤쪽 공유 아이콘이 닫기 버튼과 겹쳐 보인다. 96%로 정한다.                         |

## 반영 내용

- `EventPhoto`(`features/events/ui/event-photo.tsx`)가 상단 사진 영역, 확대 아이콘 버튼, 크게 보기 화면을 담당한다.
- 열림 상태는 `location.state.photoOpen`이다. 닫기를 연달아 입력해도 뒤로 가기는 한 번만 실행한다.
- `dialog`의 `cancel`과 `close`도 같은 닫기 처리로 연결한다. `close` 이벤트는 `dialog`가 실제로 닫힌 경우에만 처리한다.
- 여백 판정은 `contain-box.ts`의 `isOnContainedImage`에 두고 단위 테스트를 추가한다.
- `EventImage`에 선택 항목 `onLoad`를 추가한다. 목록 카드의 사용 방식은 바꾸지 않는다.
- 확대·닫기 아이콘을 `shared/ui/icons.tsx`에, 접근성 이름 3개를 ko·en·zh·vi 문구에 추가한다.
- 크게 본 상태에서 새로고침하면 방문 기록의 `state`가 남아 다시 열린다.
- 첫 브라우저 확인에서 사진이 없는 행사에도 버튼이 표시된다. `eventLink`의 빈 값 `undefined`를 `null`과 비교한 오류이며 수정한 뒤 다시 확인한다.
