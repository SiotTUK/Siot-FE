# 챗봇 답변 평가 의견 입력 (CB-04 comment)

- 작성일: 2026-11-28
- 관련 이슈 / PR: SiotTUK/Siot-FE#46

## 목적

CB-04 답변 평가 API는 선택 의견(`comment`, 500자 이하, BE에서 개인정보를 가려 저장)을 받지만 FE는 `helpful`만 보냈다. 그래서 관리자 챗봇 답변 검토 화면(ADM-08)의 `feedbackComment`가 항상 비어 있었다. "안 됐어요"의 이유를 남길 수 있게 한다.

## 핵심 요청

- 이슈 #46을 진행한다. 범위는 이슈의 할 일 목록(입력란·안내·재진입 표시·4개 언어·키보드·MSW·계약 테스트)이다.
- 이어서 PR 생성을 요청했다.

## 선택과 이유

| 검토한 방법                        | 선택                                                  | 이유                                                                                          |
| ---------------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| "안 됐어요" 클릭 시 평가 즉시 저장 | 채택(이슈 요구)                                       | 의견을 보내지 않고 닫아도 평가가 남아야 한다. 의견은 같은 PUT을 `helpful=false`로 다시 보낸다 |
| 빈 의견 처리                       | 공백 제거 후 빼고 보냄(이슈 요구)                     | 공백만 입력하면 `{ helpful }`만 보낸다. 입력란에서는 보내기 버튼을 비활성화한다               |
| 다시 연 답변의 입력란              | 닫힌 빈 상태(이슈 요구)                               | 메시지 응답(`MessageResponse`)에 의견 필드가 없다. 평가 표시만 유지한다                       |
| 입력 상태 관리                     | 컴포넌트 `useState`(AI 판단)                          | 선택 입력란 하나라 React Hook Form 없이 기존 질문 입력창과 같은 방식으로 둔다                 |
| 키보드 조작                        | 열면 입력란 포커스, Esc로 닫고 버튼으로 복귀(AI 제안) | 키보드 사용자가 열고 닫은 위치를 잃지 않게 한다                                               |
| MSW 의견 저장 위치                 | 대화별 별도 맵(AI 판단)                               | 메시지 목록 응답에 BE에 없는 필드가 섞이지 않게 한다                                          |

## 반영 내용

- `sendFeedback(conversationId, messageId, helpful, comment?)`: 공백을 지운 의견이 있을 때만 `comment`를 보낸다. `feedbackCommentMaxLength = 500`
- `useFeedback`·`rate`에 `comment`와 저장 성공 콜백
- 답변 카드 `FeedbackControls`: 선택 의견 입력란, 개인정보 안내(`chat.privacy` 재사용), 글자 수, 닫기·의견 보내기, 전송 완료 안내, `aria-expanded`·`aria-controls`
- 4개 언어 문구 6개
- MSW: 의견 검증(500자 초과 400), 공백은 삭제, 6자리 이상 숫자 가림, ADM-08 목록의 `feedbackComment` 반영
- 테스트: 의견 본문 포함·제외, 501자 거절, 메시지 응답에 의견 없음, ADM-08에서 가린 의견 확인
