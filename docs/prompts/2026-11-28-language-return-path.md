# 언어 선택을 거쳐도 로그인 후 원래 화면으로 돌아가기 (M-08·M-10)

- 작성일: 2026-11-28
- 관련 이슈 / PR: [#68](https://github.com/SiotTUK/Siot-FE/issues/68) / PR 미생성

## 목적

저장 언어와 세션이 없을 때 보호된 주소(`/events/123?from=list`)를 열면 회원 가드가 원래 경로를 `state.from`에 담아 언어 선택(`/`)으로 보낸다. 언어 선택이 회원가입·로그인으로 넘어갈 때와 인증 화면끼리 이동할 때 이 값을 넘기지 않아 로그인 후 원래 화면으로 돌아가지 못했다. 가입·온보딩을 거치는 경우에도 목적지를 유지한다.

## 핵심 요청

- #68 이슈를 수정한다.
- 가입했거나 온보딩이 필요한 계정은 F06 '내 맞춤 화면 보기' 뒤에 원래 주소로 보낸다(사용자 선택). 목적지 없이 들어온 경우는 지금처럼 맞춤 홈으로 간다.

## 선택과 이유

| 검토한 방법                                            | 선택 | 이유                                                                                                                                                                          |
| ------------------------------------------------------ | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 온보딩 후 원래 주소로 이동                             | 채택 | 사용자 선택. 이슈 완료 기준('가입·온보딩이 필요한 경우에도 목적지 유지')과 맞다                                                                                               |
| 온보딩 후 항상 맞춤 홈                                 | 제외 | 사용자 선택에 따라 제외                                                                                                                                                       |
| 인증 화면 사이: 라우터 `state.from`을 계속 넘김        | 채택 | 기존 M-08·M-10 방식(`GuestOnly`가 `state.from`을 읽음)을 그대로 쓴다. URL에 목적지를 노출하지 않는다                                                                          |
| 가입·온보딩 동안: 회원 id와 함께 sessionStorage에 보관 | 채택 | 온보딩은 F02~F06 여러 화면과 뒤로 가기를 거쳐 라우터 state로 잇기 어렵다. 회원 id가 다르면 쓰지 않고, 탭을 닫으면 사라진다 (AI 판단)                                          |
| 온보딩 끝 이동을 F06 화면의 `navigate`로 처리          | 제외 | 저장 직후 `me`가 온보딩 완료로 바뀌면 온보딩 경로 가드가 먼저 `/home`으로 보내 F06 화면이 사라진다. 그 뒤 `navigate`는 효과가 없었다(브라우저에서 확인). 가드가 이동을 맡는다 |

## 반영 내용

- `src/features/auth/return-path.ts` (신규)
  - `returnPath`: 앱 내부 경로만 허용. 외부 주소(`//`, `\`, 스킴), 인증·재설정·온보딩 화면은 제외. 기존 `use-session.ts`의 검사를 옮기고 강화했다.
  - `returnState`·`authLinkState`: 다음 인증 화면으로 넘길 state.
  - `rememberReturnPath`·`peekReturnPath`·`clearReturnPath`: 가입·온보딩 동안 회원별 보관.
- 언어 선택: 카드 → 회원가입, '이미 회원이에요? 로그인' 링크에 `from`을 넘긴다.
- 인증 화면(M02a~d): 화면 간 링크와 ‹ 뒤로 가기에 `from`을 넘긴다. ‹는 기존과 같은 경로로 가되 링크 대신 `navigate`(state 포함)로 이동한다.
- 회원 가드
  - `GuestOnly`: 로그인·가입한 회원이 온보딩 전이면 `from`을 보관하고, 없으면 이전 보관값을 지운다.
  - `RequireMember`(onboarded): 온보딩 전 회원이 보호된 화면을 열면 그 경로를 보관한다.
  - `RequireMember`(onboarding): 온보딩을 마친 회원을 보관한 경로(없으면 홈)로 보내고 보관값을 지운다.
- F06 저장 성공 시 화면에서 직접 `/home`으로 이동하던 코드를 없애고 초안만 지운다(이동은 가드).

미검증: 회원가입 전체 흐름(인증 코드 단계)은 브라우저에서 끝까지 진행하지 않았다. 가입 성공 후 이동은 로그인과 같은 `GuestOnly` 경로를 쓰고, 회원가입 화면에 `from`이 전달되는 것은 확인했다. 실제 BE 연동은 하지 않았다.
