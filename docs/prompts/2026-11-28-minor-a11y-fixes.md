# 좁은 화면 가로 스크롤·헤더 제목 잘림·홈 제목 구조 수정

- 작성일: 2026-11-28
- 관련 이슈 / PR: [#127](https://github.com/SiotTUK/Siot-FE/issues/127), [#128](https://github.com/SiotTUK/Siot-FE/issues/128), [#130](https://github.com/SiotTUK/Siot-FE/issues/130) / [#136](https://github.com/SiotTUK/Siot-FE/pull/136). 발견 경위: [#74](https://github.com/SiotTUK/Siot-FE/issues/74) 점검

## 목적

#74 점검에서 나온 경미한 문제 세 가지를 한 번에 고친다. 320 폭 데스크톱 브라우저의 15px 가로 스크롤(#127), 영어 챗봇 헤더 제목의 말줄임(#128), 홈에만 없는 `h1`(#130)이다.

## 핵심 요청

- #74에서 분리한 이슈 중 사소한 것을 한꺼번에 해결한다.
- 대상은 #127·#128·#130으로 정했다. #129(글자 크기 px → 상대 단위)는 디자인 시스템 결정이 필요하고 범위가 커서 제외했다. 포커스 관련 #124·#125·#126은 경미한 문제가 아니라 제외했다.

## 선택과 이유

| 검토한 방법                                      | 선택 | 이유                                                                                                        |
| ------------------------------------------------ | ---- | ----------------------------------------------------------------------------------------------------------- |
| #127: `body` 의 `min-width: 320px` 삭제          | 채택 | 스크롤바 폭만큼 문서보다 넓어지는 직접 원인이다. 첫 커밋(`e43f9dd`)부터 있었고 남긴 이유는 찾지 못했다      |
| #128: 공통 헤더 제목을 2줄까지 줄바꿈            | 채택 | 긴 번역이 잘리지 않는다. 헤더 줄 최소 높이 52px 안에 2줄(44px)이 들어가 한 줄 제목의 화면은 그대로다        |
| #128: 영어 문구 'Welcome Siheung Helper' 축약    | 제외 | 서비스 이름 문구라 제품 결정이 필요하고, 다른 화면·언어의 긴 제목에는 효과가 없다                           |
| #130: 홈에 화면 낭독기 전용 `h1`(하단 메뉴 이름) | 채택 | 다른 탭 화면은 `h1` 이 탭 이름이다. 상단 바 '웰컴시흥'을 `h1` 으로 바꾸면 모든 탭 화면에 `h1` 이 2개가 된다 |

## 반영 내용

- `src/styles.css`: `body` 의 `min-width: 320px` 삭제(#127).
- `src/shared/ui/screen-header.module.css`: 제목의 한 줄 말줄임(`nowrap`·`ellipsis`)을 2줄 제한(`line-clamp: 2`)과 `overflow-wrap: anywhere` 로 바꿈(#128). 공통 헤더(`ScreenHeader`)를 쓰는 모든 화면에 적용된다.
- `src/pages/home/home-page.tsx`: `<h1 className="visually-hidden">` 로 하단 메뉴의 '홈' 문구(`nav.home`, 4개 언어 기존 문구)를 추가(#130).
