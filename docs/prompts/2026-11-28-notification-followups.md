# 알림 후속: 기한 알림 시점·이메일 수신·찜한 행사 관리·모두 읽음

- 작성일: 2026-11-28
- 관련 이슈 / PR: SiotTUK/Siot-FE#35

## 목적

피그마 M09 알림 설정의 남은 항목(기한 알림 시점 D-7·D-1, 이메일로도 받기, 찜한 행사 관리)과 모두 읽음을 BE API(`leadDaysList`·`availableLeadDays`·`emailEnabled`, `PATCH read-all`, 행사 구독 목록)에 맞춰 넣는다.

## 핵심 요청

- 이슈 #35를 진행한다. 정책·디자인이 정해지지 않은 항목은 작업 전에 사용자에게 물었다.
- 사용자 결정
  - 기한 알림 시점: 체크리스트 기한·세금은 고른 값 그대로, 체류 만료는 120·60·30·14일 알림을 유지하고 D-7·D-1만 고른 대로 켜고 끈다.
  - 모두 읽음: 목록 위 오른쪽 텍스트 버튼, 안 읽은 알림이 있을 때만.
  - "신청한 행사": "찜한 행사 N개"로 쓰고, 관리를 누르면 설정 카드 안에 목록을 펼친다.

## 선택과 이유

| 검토한 방법                    | 선택                                    | 이유                                                                                                                                                        |
| ------------------------------ | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 체류 만료에 D-7·D-1만 반영     | 채택(사용자 결정)                       | D-7만 고르면 체류 만료의 120~14일 알림까지 사라지는 문제를 피한다                                                                                           |
| D-7·D-1 중 하나는 항상 켜짐    | 채택(AI 제안)                           | BE는 `leadDaysList`가 비면 400. 모두 끄기는 생활 마감 스위치로 한다                                                                                         |
| 날짜가 고른 것으로 보이는 기준 | 생활 마감 세 종류 모두 보낼 때(AI 제안) | 일부만 보내는 상태를 켜짐으로 보이지 않게 한다                                                                                                              |
| 이메일 스위치 범위             | 모든 알림 종류(행사 포함)(AI 제안)      | 시안 문구가 "이메일로도 받기 (가입 이메일)" 하나다. 일부만 켜져 있으면 기존 '일부' 안내를 쓴다                                                              |
| 안내 문구                      | 상태별 3가지(AI 제안)                   | 시안 문구 "서비스 알림 목록과 가입한 이메일로 보내요"는 이메일이 켜져 있고 인증된 경우에만 쓴다. 이메일이 꺼지면 "알림 목록에 보여요", 미인증이면 기존 문구 |
| 찜한 행사 이름                 | 행사 상세를 하나씩 불러옴(AI 제안)      | 구독 목록 API에는 행사 ID만 있다. 지운 행사는 "볼 수 없는 행사"로 보이고 ♥로 해제할 수 있다(BE 해제는 행사 행이 있으면 동작)                                |
| 체크박스(v2) 대신 스위치 유지  | 유지(AI 판단)                           | 기존 스위치의 접근성 처리를 유지하고 이번 범위를 좁힌다. 디자인 맞춤은 별도                                                                                 |

## 반영 내용

- `NotificationPreference`에 `emailEnabled`·`leadDaysList`·`availableLeadDays`, 저장 요청 타입 `NotificationPreferenceUpdate`(생략한 값은 유지)
- 설정 저장 훅을 `useUpdatePreferences(build)`로 일반화(그룹 켜기·이메일·시점 모두 같은 저장 경로)
- 설정 카드: 이메일로도 받기 스위치(미인증 안내), 기한 알림 시점 D-7·D-1 토글 버튼, 체류 만료 이전 시점 안내, 상태별 안내 문구, 찜한 행사 N개 · 관리(펼치면 행사 열기·♥ 해제)
- 모두 읽음 버튼과 `useMarkAllNotificationsRead`(목록·배지 갱신)
- MSW: 설정 기본값·검증(`leadDaysList` 허용 값, 시점 없는 종류), 생략 시 유지, `PATCH read-all`(204)
- 4개 언어 문구, 테스트(설정 계산·계약)

내 정보의 "알림 설정" 행·행 순서, 알림 없음 화면(M13)은 main에 이미 있어 바꾸지 않았다.
