# 세금 알림을 누르면 세금 상세로

- 작성일: 2026-11-28
- 관련 이슈 / PR: #134. PR 미정(초안). 이전 기록: [2026-11-26-notifications.md](2026-11-26-notifications.md)

## 목적

세금 납부 알림(`kind: TAX`)은 `linkType: SCHEDULE`, `linkCode`에 공통 세금 일정 ID를 준다. FE는 세금 상세 화면(CAL-03)이 생기기 전 기준으로 `SCHEDULE`을 달력 첫 화면으로 보내, 어느 세금인지 다시 찾아야 했다. 알림에서 바로 그 세금의 상세를 연다.

## 핵심 요청

- 요약: 사용자가 #134(수지 님 배정, FE·BE 대조에서 나온 버그)를 처리하자고 했다.

## 선택과 이유

| 검토한 방법                                | 선택 | 이유                                                                                                                                                                        |
| ------------------------------------------ | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SCHEDULE` → `/calendar/taxes/{linkCode}`  | 채택 | BE에서 `scheduleId`가 있는 알림은 세금 알림뿐이고, 그 ID는 세금 상세 API(`/api/schedules/taxes/{id}`)가 받는 공통 세금 일정 ID다(`NotificationScheduler.notifyTaxSchedule`) |
| `/calendar/schedules/{id}`(일반 일정 상세) | 제외 | BE 설명이 "SCHEDULE(세금 상세)"이고, 세금 상세가 세율·가산세 등 세금 정보를 보여 준다                                                                                       |
| `linkCode`가 숫자가 아니거나 없을 때       | 채택 | 지금처럼 달력 첫 화면(이슈의 할 일)                                                                                                                                         |

## 반영 내용

- `notificationPath`: `SCHEDULE`이고 `linkCode`가 양의 정수면 `/calendar/taxes/{linkCode}`, 아니면 `/calendar`. `CALENDAR`는 그대로 달력. 주석 갱신.
- `notifications.test.ts`: `SCHEDULE` 5 → 세금 상세, 숫자 아님·없음 → 달력.
- MSW 알림 목업: 목업의 공통 세금 일정(주민세, ID 1)으로 가는 세금 알림을 하나 추가하고 `scheduleId`를 채웠다.
- 뒤로 가기: 세금 상세의 ‹는 이전 화면(`navigate(-1)`)이라 알림 목록으로 돌아온다. 코드 변경 없음.
