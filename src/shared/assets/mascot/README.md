# 해로·토로 마스코트

- 출처: 시흥시 공식 캐릭터. 팀 Figma 디자인 시스템("해로토로 (마스코트)")에서 내려받은 원본이다.

- 형태·색상·비율을 바꾸지 않는다. 크기만 CSS로 맞춘다.
